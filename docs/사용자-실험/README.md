### 지금은 낡은 결정

- 초록불 비율을 주 지표로 쓰는 안은 10-14에 뺐다. 11-24부터 참고 수치로만 다시 들어왔다.
- 숨김 대 보임 두 조건(웹캠 제외)은 10-18에 세 조건으로 바뀌었다.
- 팀원 실시간 접속은 10-18에 기록 재생으로 바뀌었다.
- 단순 계산 과제는 10-27에 참가자 선택제로, 11-25에 자기 공부로 바뀌었다. 예전 과제 방식은 화면에 남아 있다.
- 분당 처리량이라는 주 지표와 그 가설은 11-23에 성과를 주장하지 않기로 하면서 쓰지 않는다.
- 실험실 한 방, 실험자 제어실, 실험실 노트북, 진행자 시작 신호는 11-08 원격 참가로 낡았다.
- 세 환경 비교안(11-23)은 보류됐다.

## 아직 서로 맞지 않는 곳

발표 전에 팀이 정하거나 고쳐야 한다.

1. **긴장감의 비교 대상이 문서마다 다르다.** `2026-11-23-방향-정리.md` 5-2절과 `2026-11-28-주간발표-1202-피드백-답변.md` 2절은 "혼자 대 아바타"다. 그런데 주간보고9에는 "아바타가 웹캠보다 1점 넘게 낮지 않으면 긴장감이 유지된 것"이라는 기준이 적혀 있다. 하나로 정해야 한다.
2. **`실험-설문지.md`(experiment)에 PR #609의 문항이 없다.** PR 설명에도 문장을 확정한 뒤 따로 올린다고 적혀 있다.
3. **`사용자-실험-재설계.md`(두 브랜치 모두)가 지금 설계와 다르다.** 3절 실험 환경, 4절 재생 방식, 6-3절 전송 끊김은 11-08 원격 참가와 맞지 않고, 과제와 가설(처리량)은 11-25 방향과 맞지 않는다. 문서 수정은 이슈 #195에 할 일로 남아 있다.
4. **이슈 #196(진행자 시작 신호)이 아직 열려 있다.** 11-08 원격 참가로 필요 없어졌다.
5. **`CLAUDE.md`의 두 문장이 지금 상태와 다를 수 있다 (확인 필요).** "팀원 녹화 영상은 실험용 컴퓨터에만 둔다"는 11-08의 로그인 계정만 보는 서버 업로드 결정과, "캐릭터 숨김 모드는 접속 인원 수만 보여 준다"는 10-20에 인원 수까지 숨긴 것과 다르다.

## 이번 정리(2026-11-28)에서 한 것

- 흩어져 있던 문서 네 개를 이 폴더로 옮기고 이름 앞에 쓴 날짜를 붙였다. 문서끼리 가리키는 경로도 고쳤다.
- 각 문서 맨 위에 언제 쓴 기록인지 적었다. 방향 정리의 6절(교수님께 드릴 설명)은 12월 2일 문서와 겹쳐서 안내로 줄였고, 9절은 지난 발표용이라고 표시했다.
- 논문 조사 보고서를 조사 노트와 대조해 네 곳을 바로잡았다. 대학생 현장 실험의 과제형 목표 표본(3,971명 → 그중 2,004명), Biwer 2023을 Smits와 같은 방식이라고 단정한 곳, Ramirez Perez의 결과 요약, Shockley 2021의 설문 시각이다.
- 조사 노트 8개(논문별 상세 기록)는 올리지 않았다. 7개는 보고서와 대부분 겹치고, 나중에 원문으로 확인되기 전의 "미확인" 문장과 지금 설계와 반대되는 권고(웹캠과 같은 성과 입증, 스카의 80% 이상이라는 기준 등)가 남아 있어서다. 필요하면 김현에게 받는다.

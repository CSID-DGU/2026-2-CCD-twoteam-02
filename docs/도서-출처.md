# 도서 출처 표 (앱 안 도서관)

2026-11-02에 위키문헌(ko.wikisource.org)의 각 작품·저자 페이지를 열어 확인한 내용이다. 공유마당(gongu.copyright.or.kr)은 작품 페이지를 열어 보지 못해 아래 표에 출처로 쓰지 않았다. 판본 상태는 페이지에 저본이 적혀 있지 않은 경우가 많아, 본문 표기를 보고 추정한 것이다. 이 표는 앱에 넣은 책의 출처와 이용 조건을 남기는 기록이다. 사람이 확인해 8권을 넣기로 했다(아래 "결정").

위키문헌 주소는 모두 `https://ko.wikisource.org/wiki/` 뒤에 붙는다. 이용 조건에 적힌 "PD-old-70" 같은 것은 위키문헌이 페이지에 붙인 저작권 만료 표시다. 위키문헌 글 자체는 CC BY-SA 4.0이라고 모든 페이지 하단에 적혀 있다.

## 사망 연도 확인

위키문헌 저자 페이지(`저자:이름`)에 적힌 생몰 연도를 읽고 적었다. 김유정 1937, 현진건 1943, 이효석 1942, 나도향 1926, 김동인 1951, 이상 1937, 채만식 1950, 윤동주 1945, 김소월 1934, 한용운 1944. 1963년 이후 사망한 작가는 없다. 나도향은 작품 페이지의 안내문에 다른 연도가 섞여 적혀 있어, 저자 페이지 값을 따랐다.

## 결정 (2026-11-02, 사람 확인)

- 앱에 넣은 책은 8권이다. 한국 단편 6권(봄봄, 동백꽃, 운수 좋은 날, 메밀꽃 필 무렵, 감자, 날개), 한국 장편 1권(태평천하), 시 1권(윤동주 시 묶음). 세 분야 모두 채웠다.
- 김소월·한용운 시 묶음은 보류한다(표의 포함 여부 "보류"). 벙어리 삼룡이는 옛 자모 때문에 제외한다.
- 저본이 페이지에 적혀 있지 않은 4권(봄봄, 동백꽃, 감자, 태평천하)은 "저본 미표시"로 표에 남기고, 한국저작권위원회 상담 때 함께 묻는다.
- 본문은 위키문헌 원문에서 위키 표시(틀·분류·링크·꼬리말)만 지우고 글자는 고치지 않았다. 앱은 읽기 화면에 출처 주소(`sourceUrl`)를 보여 준다.

## 남은 질문

1. 위키문헌 표시는 대부분 한국 기준 만료만 말한다. 1931~1977년 발표작은 미국에서 아직 보호될 수 있다는 경고가 모든 페이지에 있다. 한국에서만 서비스하면 문제없는지 한국저작권위원회 상담 때 함께 묻는다.
2. 위키문헌 글 자체는 CC BY-SA 4.0이다. 원문을 그대로 옮긴 글은 새 저작권이 없다고 볼 수 있는지, 저작자 표시·동일 조건 의무가 생기는지 해석이 필요하다.
3. 공유마당(gongu.copyright.or.kr)에 같은 판본이 있는지는 확인하지 못했다.
4. 윤동주 89편이 1955판 전체 수록 시와 같은지 맞춰 보지 못했다(위키문헌에 하위 문서가 있는 시만 넣음).
5. 소월·용운을 나중에 넣을 때, 시마다 실린 옛 표기 원문판과 현대어판(편집자가 쓴 글이라 CC BY-SA 의무가 생길 수 있음)을 가려야 한다.

# 가방 속 시계 (스톱워치·알람) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 가방에 민트 회중 스톱워치 모양의 시계를 넣어, 꺼내면 스톱워치와 알람(몇 분 뒤·시각)을 쓰고, 알람은 시계를 닫아도·다른 탭에서도·소리 끔/방해금지여도 제때 울리게 한다.

**Architecture:** 상태 변화·시각 계산·표시 글자는 순수 함수(`clockLogic.ts`, Node 검사). 상태는 계정별 localStorage 에 "시각 기준"으로 저장하고 작은 모듈 저장소(`useClock`)가 화면들에 나눠 준다. 알람 감시는 가방(로그인 화면 어디서나)에서 `workerInterval` 1초로, 소리는 Web Audio(`alarmSound.ts`).

**Tech Stack:** React 19, TypeScript, Vite. 새 라이브러리·소리 파일·DB 변경 없음.

**Spec:** `docs/superpowers/specs/2026-11-02-bag-clock-design.md`

## Global Constraints

- 브랜치 `feat/wonjun/bag-clock`(develop 기준), worktree `.claude/worktrees/bag-clock`. PR base `develop`. DB 변경 없음.

- 알람 하나만(새로 맞추면 이전 것 사라짐). 몇 분 뒤 1~600분, 빠른 버튼 5·10·25·40·50. 시각은 지났으면 다음 날. 스톱워치와 동시 동작.

- 울릴 때: Web Audio "띠리리리"(높은 음 4번, 0.6초 쉼 반복), **소리 끔·방해금지와 무관**, 소리 1분 뒤 자동 멈춤, 화면 가운데 끄기 창(시계 닫혀 있어도), 시계 흔들림, 탭 제목 "⏰ 알람!" 1초마다 번갈아, 포인터 잠금 풀기. 소리가 막혔으면 끄기 창에 "소리가 막혔어요. 아무 데나 한 번 눌러 주세요".
- 알람을 맞추는 버튼을 누를 때 AudioContext 생성·resume.
- 주석·화면 글자 한국어, 기준값은 파일 위 상수, 순수 파일 import 에 `.ts`.

### Task 1: 시계 순수 로직 (`clockLogic.ts`)

**Files:** Create `src/planner/clockLogic.ts`

**Interfaces — Produces:**
```ts
export const MAX_MINUTES = 600, QUICK_MINUTES = [5, 10, 25, 40, 50], SOUND_STOP_MS = 60_000
export type Stopwatch = { startedAt: number | null; accMs: number }   // 돌고 있으면 startedAt
export type Alarm = { at: number; kind: 'after' | 'at'; minutes: number | null }
export type ClockState = { sw: Stopwatch; alarm: Alarm | null; ringing: Alarm | null }
export const INITIAL_CLOCK: ClockState
swElapsed(sw: Stopwatch, now: number): number
swToggle(sw: Stopwatch, now: number): Stopwatch
swReset(sw: Stopwatch): Stopwatch                // 돌고 있으면 그대로
parseMinutes(text: string): number | null        // 정수 1~600 만
alarmAfter(minutes: number, now: number): Alarm
alarmAt(hhmm: string, now: number): Alarm | null // 'HH:MM', 지났거나 지금이면 다음 날
remainingMs(alarm: Alarm, now: number): number   // 0 이상
formatSw(ms: number): { main: string; sub: string }
formatRemain(ms: number): string                 // 초 올림, MM:SS 또는 H:MM:SS
ringText(alarm: Alarm): string                   // after: "40분 지났어요 (15:30)", at: "15:30 이에요"
parseClockState(raw: unknown): ClockState
```

- [ ] **Step 1: 검사 작성 후 실패 확인** (`.superpowers/sdd/<plan>/t1.mjs`)

assert.equal(C.parseMinutes("601"), null); assert.equal(C.parseMinutes("2.5"), null); assert.equal(C.parseMinutes("abc"), null);
const a = C.alarmAfter(40, T(14, 50));
assert.deepEqual(a, { at: T(15, 30), kind: "after", minutes: 40 });

### Task 3: 상태 저장소·알람 감시 (`useClock.ts`)

**Files:** Create `src/planner/useClock.ts`

**Interfaces:**
- Consumes: Task 1 전부, Task 2 전부, `workerInterval`, `useSession`
- Produces:
  - `useClock(): { state: ClockState; toggleSw(): void; resetSw(): void; setAlarm(a: Alarm): void; cancelAlarm(): void; dismiss(): void; soundBlocked: boolean }`
  - `useClockWatcher(): void` — BagLayer 에서 한 번만. 1초마다 `alarm` 이 지났으면 `ringing = alarm, alarm = null`로 바꾸고 저장, 소리 시작(`SOUND_STOP_MS` 뒤 멈춤), 탭 제목 깜빡임 시작, 포인터 잠금 풀기. `ringing`이 null 이 되면 소리·제목 원래대로.
  - `useNow(intervalMs: number): number` — 창이 열린 동안만 화면 숫자 갱신(스톱워치 50ms, 알람 탭 500ms).

- [ ] **Step 1: 작성** — 모듈 저장소: 키 `dooteum.clock.<user id>`, 읽을 때 `parseClockState`, 바뀔 때 저장 + 구독자 알림, 다른 탭의 `storage` 이벤트로 다시 읽음. 로그인 전(id 없음)엔 `INITIAL_CLOCK`·저장 안 함. `setAlarm` 을 부르는 버튼에서 `prepareAlarmSound()` 먼저(화면 쪽, Task 4). 새로고침 뒤 `ringing` 이 남아 있으면 감시가 다시 소리를 시도하고 막히면 `soundBlocked = true`(끄기 창 안내), 다음 클릭에서 `prepareAlarmSound` 후 다시 시도.
- [ ] **Step 2: lint·build** — Commit `feat: 가방 시계 상태 저장과 알람 감시 (숨긴 탭에서도)`

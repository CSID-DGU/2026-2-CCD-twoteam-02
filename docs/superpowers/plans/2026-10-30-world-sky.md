# 월드 하늘과 시간 — 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 광장에 현실 시각(서울)을 따르는 하늘을 얹는다. 해·달(위상)이 뜨고 지고, 밤에는 남색 하늘·별·가로등·창문 불빛. (#316)

**Architecture:** 계산은 순수 함수 `src/world/skyLogic.ts`(시각 읽기, 해·달 위치, 달 위상, 화면 값 `SkyState`). 그리기는 `src/world/WorldSky.tsx`가 매 프레임 `skyState`를 계산해 drei `Sky`·밤 덮개·직접 만든 별·달 판·빛을 직접 바꾼다(React 다시 그리기 없음). 가로등·창문은 `WorldDecor`의 공용 재질을 `setNightGlow(night)`로 바꾼다. 하늘 부품은 레이어 2 라 미니맵에 안 보인다.

**Tech Stack:** React 19, React Three Fiber 9, drei 10(`Sky`, `Billboard`), three 0.186, TypeScript. 순수 로직은 Node 24 `--experimental-strip-types`로 스크래치패드 검사 스크립트(저장소에 넣지 않음). 화면은 lint·build 와 로그인 없는 임시 미리보기.

**Spec:** `docs/superpowers/specs/2026-10-30-world-sky-design.md`

- 위치 서울 37.5665°N, 126.9780°E. 서울 시각 = UTC+9 (서머타임 없음).
- 기준값(스펙 4절): 밤 시작 해 고도 −2°, 완전한 밤 −12°, 주변광 1.0 → 0.45 / 흰색 → `#8fa3d6`, 햇빛 0.9 (고도 15° 이상 흰색, 0° 쪽 `#ffb070`), 달빛 0.25 × lit × night `#9fb8ff`, 별은 night 0.6 부터, 기준 삭 2000-01-06 18:14 UTC, 삭망월 29.530589 일.
- 거리(스펙 5절): `Sky` distance 450, 밤 덮개 반지름 400(머리 위 `#0b1630` → 지평선 `#24365f`), 별 반지름 350 약 2,500개, 달 거리 330. 점광원 4개 `#ffd28a` 반경 12m(광장 네 모서리 가로등 (±9, ±9), 높이 3). 가로등 빛남 0.3 → 1.6, 창문 0 → 0.9 `#ffcf7a`.
- 하늘 방향 → 3D: `x = cos a · sin z`, `y = sin a`, `z3 = −cos a · cos z` (방위 북 0·동 +π/2).
- 하늘 부품은 레이어 2(`SKY_LAYER`). 화면 카메라만 레이어 2 를 켠다. 빛은 레이어 0 그대로.
- 주석 한국어, 기준값은 파일 위쪽 이름 붙인 상수, 커밋 메시지 `종류: 한국어 설명`. 30FPS.

## Review Focus

1. 자정을 넘거나 날짜가 바뀌는 순간(23:59 → 00:00 서울)에 해·달·`night`가 튀면 안 된다. — Task 1 연속성 검사(1분 간격으로 하루 내내 `night` 차이 < 0.05).
2. 서울이 아닌 시간대의 컴퓨터에서도 같은 하늘이어야 한다(절대 시각 기준). `?time`도 서울 시각이다. — Task 1 `parseClock` 검사에서 `nowMs`만으로 계산(시간대 함수 `getHours` 쓰지 않음).
3. `?time`만 주면 그 시각에 멈추고, `?speed`만 주면 지금부터 빨리 흐른다. 틀린 값은 그 값만 무시. — Task 1 검사.
4. 그믐(lit≈0)이나 달이 지평선 아래일 때 달빛이 0 이어야 밤 조명이 이상하게 밝지 않다. — Task 1 `skyState` 검사.
5. 하늘이 미니맵에 끼면 월드 바깥이 하늘색으로 보인다. — Task 3 Step 4 확인 항목(미니맵 바깥 어두움).

  ```ts
  export const SEOUL = { lat: 37.5665, lon: 126.978 }
  export const SKY_LAYER = 2
  export type SkyPos = { altitude: number; azimuth: number } // 라디안, 방위 북 0·동 +π/2
  export type Vec3 = { x: number; y: number; z: number }
  export type Clock = { start: number; base: number; speed: number } // ms
  export type SkyState = {
    sun: SkyPos
    moon: SkyPos & { phase: number; lit: number }
    night: number // 0 낮 ~ 1 밤
    light: { dir: Vec3; intensity: number; color: string } // 방향광 (해 또는 달 쪽에서 오는 방향)
    ambient: { intensity: number; color: string }
    glow: number // 가로등·창문 빛남 0~1 (= night)
    stars: number // 별 투명도 0~1
  }
  export function sunPosition(ms: number): SkyPos
  export function moonPhase(ms: number): { phase: number; lit: number }
  export function moonPosition(ms: number): SkyPos
  export function toDirection(p: SkyPos): Vec3
  export function skyState(ms: number): SkyState
  export function parseClock(search: string, nowMs: number): Clock
  export function worldTime(clock: Clock, nowMs: number): number // = start + (nowMs − base) × speed
  ```

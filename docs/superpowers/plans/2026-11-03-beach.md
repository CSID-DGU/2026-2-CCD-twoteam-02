# 캠빛 해변 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 광장 문으로 가는 세 번째 바깥 공간 `/beach`를 만들어, 바다를 보며 비치체어에서 공부하고 파도 소리와 밤 조명을 즐기게 한다.

**Architecture:** 광장·캠퍼스가 쓰는 `WorldConfig` + `WorldScene` 구조에 `beach` 월드를 하나 더한다. 좌석·파도 크기 같은 계산은 `src/world/beachLogic.ts` 순수 함수, 배치는 `src/world/beach.json`, 풍경은 해변 전용 R3F 컴포넌트, 소리는 `ambience.ts`의 새 종류다. 공부 흐름은 벤치와 같은 `sit_cafe_seat`와 지점 `beach`를 쓴다.

**Tech Stack:** React 19, TypeScript, React Three Fiber, Web Audio, Supabase. 새 라이브러리·소리 파일·텍스처 파일 없음.

**Spec:** `docs/superpowers/specs/2026-11-03-beach-design.md`

## Global Constraints

- 브랜치 `feat/wonjun/beach`(develop 기준), worktree `.claude/worktrees/beach`. PR base `develop`. `experiment`에 넣지 않는다.
- 커밋·푸시·PR·DB 실행은 사용자가 요청할 때만 한다. 태스크에 커밋 단계를 두지 않는다.
- 이름 `캠빛 해변`, 주소 `/beach`, 월드 id·채널·접속 장소·지점 slug 모두 `beach`.
- 좌석 24개, 파라솔 12개(파라솔 하나에 두 자리). DB 좌석 번호 1~24. Player 자리 번호는 `BENCH_SEAT_BASE + 번호`.
- 물에는 들어갈 수 없다. 앉은 시점은 바다를 본다.
- 테스트 도구 없음. 순수 로직은 `node:assert` 스크래치 검사, JSON을 읽는 모듈은 esbuild로 묶어 실행한다. 스크래치 파일은 저장소 밖 스크래치패드에 둔다.
- 태스크마다 `npm run lint`, `npm run build` 통과. 주석·화면 글자 한국어. 기준값은 파일 위 상수.
- 광장·캠퍼스·지점 화면은 달라지지 않는다. 일반 노트북 30FPS 이상(트래킹 켠 착석 공부 포함), 실시간 광원은 다른 바깥 공간과 비슷한 수.

## Review Focus

1. **창을 가린 탭·소리 막힘:** 첫 클릭 전이면 소리가 없다가 누르면 나고, 페이지를 떠나면 멈춘다. → Task 5 `stop` 확인.
2. **자리에 앉은 채 새로고침·세 번째 월드 복귀:** 지점 없이 돌아오는 `from`, 접속 복귀(`my_current_place`)가 해변으로 돌아온다. → Task 2 확인.
3. **다른 코드가 `plaza | campus` 두 값만 가정:** 친구 따라가기, 신고, 지도, 접속 표시가 해변에서 깨지지 않는다. → Task 2 grep 체크.
4. **파라솔이 시야를 가림:** 모든 자리의 정면 시선이 파라솔에 막히지 않는다. → Task 1 `sightClear` 검사.
5. **물가·경계에 갇힘, 의자 사이 통과 불가:** 모든 자리 앞까지 걸어갈 수 있고 바다로 못 들어간다. → Task 1 걷기 시뮬레이션.

### Task 1: 배치와 순수 로직

**Files:** Create `src/world/beachLogic.ts`, `src/world/beach.json`. Modify `src/world/worldLogic.ts`

**Interfaces — Produces:**
```ts
export type BeachSpec = { shoreZ: number; rows: number[]; columns: number[]; chairGap: number } // PlazaLayout.beach
export const CHAIR_BOX = { w: 0.6, d: 1.4 }
export const PARASOL_R = 1.3 // 천 반지름 (m)
export function beachSeats(b: BeachSpec, base: number): Spot[]     // 24개, rot π(바다 = -z)
export function parasolSpots(b: BeachSpec): { x: number; z: number }[] // 12개
export function beachObstacles(b: BeachSpec, size: { w: number; d: number }): Box[] // 의자·파라솔 기둥·물가 벽
export function waveLevel(z: number, shoreZ: number): number // 0.25~1, 물가 1
export function sightClear(seat: Spot, parasols: { x: number; z: number }[], eyeY: number): boolean
```

- [ ] **Step 1:** `beach.json`을 만든다: 크기 64×44, 이름 `캠빛 해변`, `beach: { shoreZ: -8, rows: [-3, 3], columns: [-20,-12,-4,4,12,20], chairGap: 1.4 }`, 시작 `{x:0, z:15, heading:π}`, `gates: [{to:'plaza', x:0, z:20.8, w:8, facing:'north', label:'캠빛 해변'}]`, 야자수 `trees`, 가로등 `lamps`, `buildings: []`.
- [ ] **Step 2:** 검사를 먼저 쓴다: 좌석 24개와 번호 중복 없음, 모두 `rot≈π`, 파라솔 12개, `waveLevel(shoreZ)==1`이고 z가 커질수록 줄어 0.25에서 멈춤, 모든 자리 `sightClear===true`, 스폰에서 BFS(`stepWithObstacles`, 반지름 0.3)로 모든 자리 0.9m 안, 게이트까지 도달, `z < shoreZ`인 칸 도달 0개.
- [ ] **Step 3:** 함수를 구현해 통과시킨다. `PlazaLayout`에 `beach?: BeachSpec`, `WorldId`에 `'beach'`를 더하고 `plazaObstacles`가 `beachObstacles`를 포함하게 한다. 광장·캠퍼스 결과가 전과 같은지 상자 개수로 확인한다.

# 스터디 플래너: 노트처럼 넘기기 + 내 글씨체 고르기 (설계)

- 날짜: 2026-11-01
- 담당: 최원준
- 대상 브랜치: `develop` (서비스). 실험(`experiment`)과 무관
- 관련: 가방·플래너 첫 구현 PR #385, 가방 버튼 위치 PR #386

## 1. 왜

가방 속 스터디 플래너(`src/planner/`)는 지금 손잡이 줄의 ◀ ▶ 버튼으로 날짜를 바꾼다. 화면에는 늘 한 장만 보여서, 며칠을 써 왔는지가 눈에 들어오지 않는다.

원하는 장면은 **어제 쓴 페이지를 다시 넘겨 보는 것**이다. 넘길 때 **써 온 장이 쌓여 있는 게 보여서 "이만큼 했구나" 하는 쾌감**이 드는 게 목표다.

같이 하는 일: 내가 직접 쓴 글씨의 글씨체를 셋 중에서 고르게 한다.

## 2. 목표 / 하지 않을 것 / 실패로 보는 것

**목표**
1. 플래너가 **한 장씩 겹쳐 쌓인 종이 더미**로 보인다. 지금까지 쓴 날이 많을수록 더미가 두꺼워진다.
2. ◀ ▶ 대신 **종이 모서리를 끌어 넘긴다.** 지난날로도, 앞날로(최대 7일)도 간다.
3. 플래너·메모에 직접 쓴 글씨의 **글씨체를 3가지 중에서 고른다.** 고른 값은 계정에 저장된다.

**하지 않을 것**
- 두 쪽 펼침(왼쪽 어제·오른쪽 오늘) 노트. 시안 A였고 사용자가 B(겹친 종이)를 골랐다.
- 날짜 옆 색 탭(인덱스) 모양. 시안 C, 고르지 않음.
- 월 달력·과목별 비율(기록 화면 개편)은 별도 작업. 이 문서 범위가 아니다.
- 플래너 칸 구성(`PlannerSheet` 안의 내용)이나 저장 방식(`planner_pages`) 변경.
- 새 라이브러리 추가(넘기는 효과는 CSS·React 로).

**실패로 보는 것 (동작은 해도)**
- 더미가 실제로 쓴 날과 상관없이 늘 같은 두께라 "쌓였다"는 느낌이 없다.
- 넘기는 효과가 끊기거나, 넘긴 뒤 아래 장이 빈 종이로 깜빡였다가 나중에 채워진다.
- 글씨체를 바꿨는데 바뀌었는지 모른다 / 글씨가 칸 밖으로 넘친다.
- 플래너 창이 지금보다 커져 화면을 더 가린다.

## 3. 정해진 것 (사용자 결정)

### 3.1 모양: 한 장씩 겹친 종이 (시안 B)
- 창 크기는 지금 그대로(`SHEET_W`×`SHEET_H` × 배율). 맨 위에 보고 있는 날의 장이 있다.
- 그 뒤로 **쓴 날 장들이 조금씩 비뚤게(회전·어긋남) 겹쳐** 보인다. 쓴 날이 많을수록 겹친 장이 많아져 더미가 두꺼워 보인다.

### 3.2 넘기기
- **지난날로**: 맨 위 장의 **오른쪽 아래 모서리를 끌면** 장이 휘면서 넘어가고, 아래에 있던 전날 장이 드러난다.
- **앞날로**: **왼쪽 아래 모서리를 끌면** 새 빈 장이 한 장 덮이듯 올라오며 다음 날 장이 된다. **오늘부터 7일 뒤까지만** 간다. 그 이상은 모서리가 넘어가지 않는다.
- **두 묶음 (사용자 결정)**: 진짜 노트처럼, 보고 있는 장 **아래 더미 = 그날보다 앞선 쓴 날**(지난날로 갈수록 얇아짐), **넘겨 온 장 = 옆(오른쪽)에 따로 쌓이는 묶음**(넘길수록 두꺼워짐). 표시는 "쓴 날 47장 중 37번째"처럼 전체와 지금 위치를 같이. 오늘 장을 보고 있으면 넘겨 온 묶음은 없다. 보이는 장 수 상한(4.1)은 묶음마다 따로 적용.
- 맨 위 장 바로 아래 한 장은 실제 전날 내용(미리 읽어 둔 것, 빈 날이면 빈 장)이고, 그 아래 더미 장들은 모양(가장자리만 보이는 종이)이다.
- 아직 오지 않은 날은 더미에 쌓지 않고 **위에 덮는 모양**으로 지난날과 구분한다.
- **"오늘" 버튼은 남긴다.** 한참 거슬러 갔을 때 한 번에 돌아오기 위해.
- 지난날로 넘길 때 **빈 날도 건너뛰지 않고 하루씩** 간다(날짜가 이어져야 "어제"가 진짜 어제).
- ◀ ▶ 버튼은 없앤다(모서리 넘기기로 대신).

### 3.3 내 글씨체 3가지
- 처음 후보였던 부산단디손글씨는 공개 웹폰트가 없고 원본이 OTF 6.2MB(수정 금지)라 빼고, 사용자가 **그리운 묘은또박체**로 바꿨다. Google Fonts 손글씨 후보(Gaegu·나눔손글씨 펜·Hi Melody·감자꽃·Poor Story)는 사용자가 고르지 않음.
| 이름 | 저작권 | 웹에 넣기 | 불러오는 곳 |
|---|---|---|---|
| 오춘기 김작가 (지금 글씨, 기본값) | 그리운 × 국립한글박물관 | 허용 (index.css 주석) | 지금 쓰는 그리운 웹폰트 주소 그대로 |
| 상주다정다감체 | 상주시 (제작 TOGETHERGROUP) | 허용 — 산돌구름 라이선스 표 "임베딩: 웹사이트 서버 내 폰트 탑재 사용 가능", 상업적 재판매만 금지 | `https://cdn.jsdelivr.net/npm/@noonnu/sangju-dajungdagam@0.1.0/index.css` 안의 woff (font-family `SANGJUDajungdagam`). 지금 교보손글씨도 같은 `@noonnu` jsDelivr 방식 |
| 그리운 묘은또박체 | 그리운 × 묘은 | 허용 — 눈누 라이선스 표 "임베딩: 웹사이트·프로그램 서버 사용 가능", 폰트 파일 수정·재배포·판매만 금지 | `https://cdn.jsdelivr.net/gh/projectnoonnu/2601-1@1.0/Griun_Myoeunddobak-Rg.woff2` (font-family `BelovedMyoeunttobak`, woff2). **약 3.8MB** (오춘기 0.7MB, 상주 0.4MB) |

- 고르는 곳: **플래너 손잡이 줄의 형광펜 옆 "펜"**. 버튼 3개를 나란히 두고, 버튼 안 글자("가나다")를 **각자의 글씨체로 써서** 무엇을 고르는지 보이게 한다. 고른 펜은 형광펜처럼 테두리·✓로 표시.
- 바꾸면 **지난 페이지를 포함한 모든 플래너 글씨와 붙여 둔 메모 글씨가** 그 글씨체로 바뀐다(페이지마다 글씨체를 저장하지 않음).
- 인쇄된 글자(날짜·칸 이름, `PRINT`)는 바뀌지 않는다.
- 고른 값은 **계정에 저장**(다른 기기에서 로그인해도 같은 글씨).

## 4. 만드는 사람에게 맡기되 제가 정한 것 (사용자 확인 전 기본값)

### 4.1 "쓴 날"과 더미 두께
- **쓴 날** = 그날(새벽 5시 기준, `plannerDayOf`) 플래너 장에 글자를 하나라도 썼거나 칠했거나, 그날 집중(초록) 기록이 있는 날. 빈 날은 더미 두께에 세지 않는다.
- **오늘 뒤(앞날)에 미리 써 둔 장은 쓴 날로 세지 않는다.** 쓴 날은 오늘까지만 센다(아직 오지 않은 날은 더미에 쌓지 않는다는 3.2 와 맞춤).
- **지난날로는 처음 쓴 날까지만** 넘긴다. 그보다 앞은 모서리가 넘어가지 않는다(끝없이 빈 장이 나오지 않게). 쓴 날이 하나도 없으면 오늘이 맨 아래.
- 더미가 화면 밖으로 넘치지 않게 **겹쳐 보이는 장 수에 상한**을 둔다(예: 8장 — 파일 위 상수). 쓴 날 수에 따라 1장 → 상한까지 늘어난다.
- 더미 아래에 **"쓴 날 N장"** 숫자를 작게 같이 보여 준다(상한을 넘은 뒤에도 늘어나는 게 보이게).
- 쓴 날 수 계산은 순수 함수로 `plannerLogic.ts`에(예: `writtenDays(pages, segments)`), 두께(보여 줄 장 수)도 순수 함수로. Node 로 검사.
- 쓴 날 수를 읽는 방법(planner_pages 전체 행 + 집중 기록 날짜)은 만드는 사람이 정한다. 단, 플래너를 열 때 한 번 읽고 넘길 때마다 다시 읽지 않는다.

### 4.2 넘기는 효과
- 새 라이브러리 없이 CSS transform(3D 회전·휘어 보이는 그림자 그라데이션)으로.
- **넘기기 전에 다음에 드러날 장(전날·다음 날)의 내용을 미리 읽어 둔다.** 넘긴 뒤 빈 종이로 깜빡이지 않게.
- 끌다가 절반을 못 넘기고 놓으면 제자리로 돌아간다. 절반을 넘기면 끝까지 넘어간다.
- **짧게 누르기(클릭·탭)만 해도 한 장 넘어간다.** 폰에서 끌기가 어려운 경우 대비. 폰은 손가락으로 같은 동작.
- 모서리에 마우스를 올리면 살짝 들려 보이게(넘길 수 있다는 걸 알리게).
- 장을 넘기면 지금처럼 보던 장의 쓰던 내용을 저장(`usePlannerPage`의 flush)한다.
- 손잡이 줄 끌기(창 옮기기)·종이 안 입력 칸 클릭과 모서리 끌기가 섞이지 않게 모서리 영역을 따로 둔다.

### 4.3 글씨체
- `paperStyle.ts`의 `HAND` 고정값을 **고른 글씨체에 따라 바뀌는 값**으로 바꾼다(예: 글씨체 목록 상수 + 지금 글씨체를 주는 훅/컨텍스트). `PlannerSheet`·`StickyNote`·`BagLayer`의 손글씨가 모두 따라 바뀐다.
- 글씨체마다 크기가 달라 칸을 넘칠 수 있으므로 **글씨체별 크기 배율**(상수)을 둔다. 지금 크기는 오춘기 김작가 기준.
- 세 글씨체 모두 외부 웹폰트 주소에서 불러온다(저장소에 폰트 파일을 넣지 않음). `index.css`에 `@font-face`와 출처·라이선스 주석을 지금 오춘기 김작가처럼 적는다. 파일을 변환·잘라내지 않는다(수정 금지).
- 브라우저는 `@font-face`로 선언만 한 글씨체는 실제로 쓰일 때만 내려받는다. **묘은또박체가 3.8MB라, 고르기 버튼의 "가나다" 미리보기는 글씨체 파일 대신 작은 그림 파일(PNG, `public/` 에 둠)로 보여 준다.** 그래서 그 글씨체를 실제로 고른 사람만 글씨체 파일을 받는다. (미리보기 그림은 만드는 사람이 그 글씨체로 써서 캡처해 만든다.)
- 글씨체를 고른 직후 파일을 받는 동안은 지금 글씨로 보이다가 받아지면 바뀐다(`font-display: swap`).

### 4.4 계정 저장 (DB)
- `profiles`에 컬럼 하나 추가: 예 `hand_font text not null default 'ochungi' check (hand_font in ('ochungi','sangju','myoeun'))`.
- 새 마이그레이션 `supabase/migrations/0048_hand_font.sql`. 기존 RLS("본인 프로필만 조회/수정")가 그대로 적용되므로 정책 추가 없음. 남이 내 글씨체를 볼 일은 없다.
- 읽기·쓰기는 지금 `useMyAvatar`처럼 profiles 를 읽고 update 하는 작은 훅으로.
- 게스트(익명 로그인, 0045_guest)도 profiles 행이 있으므로 같은 방식으로 동작한다.
- **배포 순서**: 마이그레이션이 있으므로 PR 머지 **전에** 서비스 Supabase(`lkvsbdbssrictnrxmdig`)에 SQL 을 먼저 실행(육심호에게 요청). PR 설명에 "적용할 DB: 서비스, 0048_hand_font.sql".
- 컬럼이 아직 없을 때(실행 전) 읽기 실패하면 기본 글씨체로 보여 주고 화면이 깨지지 않게 한다.

## 5. 그대로 두는 것
- 플래너 창 손잡이 줄의 나머지(제목, 형광펜, 저장 상태, － ＋ 크기, ✕ 넣기), 창 옮기기·배율 기억.
- `planner_pages` 표와 저장 방식(0.8초 모아서 저장), 시간표 자동 칠하기.
- 새벽 5시 날짜 경계.

## 6. 확인 방법
- 순수 로직(쓴 날 수, 보여 줄 장 수, 앞날 7일 제한, 날짜 이동)은 Node 로 시나리오 검사.
- `npm run lint`, `npm run build`.
- 화면은 사용자가 `npm run dev`로: 더미 두께가 쓴 날만큼인지, 넘길 때 깜빡임 없는지, 7일 뒤에서 멈추는지, 글씨체 3개가 각각 바뀌고 칸을 넘치지 않는지, 폰(개발자 도구 기기 모드)에서 탭·끌기로 넘어가는지.

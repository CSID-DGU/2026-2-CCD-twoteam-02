# 각본 시험 (트래킹 판정 정확도 기술 평가) 설계

- 작성: 최원준, 2026-10-15 / 구현에 맞춰 고침: 2026-10-16 / 측정 행동 14~17과 행동별 반복 추가: 2026-10-22 (`docs/판정-기준-근거.md` 10절, 계획 `docs/superpowers/plans/2026-10-22-script-test-measures.md`)
- 관련: `docs/사용자-실험-재설계.md` 5-1절(평가 두 갈래), 8절 8번(각본 시험표), Issue #119·#120·#80
- 순서: 카메라 가이드라인 개편(#80, Pose 하나로 합치기 포함)을 먼저 끝낸 뒤 이 시험을 구현한다. 가이드라인 없는 판정(기준 결과)은 개편과 무관하므로 "고치기 전 측정"은 그대로 유효하다.
  - (2026-10-16 상태) 가이드라인 개편(PR #133)과 자동 보정·판정 개편(PR #136·#143)은 develop에 머지됐고, 각본 시험 패널을 구현했다. 빠른 점검판은 2026-10-17 팀 대면 회의 때 세 명이 한다.

## 1. 목적

트래킹 판정(초록·노랑)과 공부 시간 기록이 웹 서비스 기능으로 쓸 만큼 정확한지 **정답을 미리 정해 둔 행동**으로 잰다.
순서: 지금 정확도 재기 → 고치기 → 다시 재기. 고친 효과를 숫자로 보이려면 고치기 전에 먼저 잰다.

- 실제 사용 중에는 정답(그때 정말 공부했는지)을 모르므로 정확도 수치를 낼 수 없다. 실제 사용의 오판 신고(#121)는 각본에 없던 오판을 찾는 용도로만 쓴다.
- 제안서 성공지표와 대응: 판정 정확도 80% 이상, 필기 중 오판율 10% 이하, 공부 시간 기록 오차 ±10% 이내.
- 사용자 실험(B vs C)과는 다르다. 각본 시험은 **팀원**이 **사용자 실험 전에** 한다. 사용자 실험에서 보조 지표로 쓰는 자리 이탈 판정이 믿을 만한지도 이 시험으로 확인한다.

## 2. 두 가지 판: 빠른 점검판과 정식판

| | 빠른 점검판 | 정식판 |
|---|---|---|
| 용도 | 어디서 틀리는지 찾기 | 제안서 지표 보고 |
| 반복 | 행동마다 1회, 목록 순서대로 (17개) | 행동마다 `repeats`회, 순서 섞기 — 오판 위험 행동(2·3·4·8·11)과 휴대폰 확인(17)은 3회, 측정 14·15는 2회, 나머지 1회 = 31회 (2026-10-22) |
| 사람 | 최원준 (10-17 회의에서는 세 명 모두) | **팀원 3명 + 팀 외 2명** (2026-10-22 결정). 측정값은 기준을 만드는 값이라 팀원만으로는 부족하다 |
| 시간 | 행동 약 19분 + 쉬는 시간 | 1인 행동 약 30분 + 쉬는 시간, 나눠서 가능 |
| 시점 | 지금 (고치기 전) | 고친 뒤, 사용자 실험 전 |

빠른 점검판에서 틀린 행동은 그 행동만 2~3번 더 해서 원인을 확인한다. 빠른 점검판 결과는 정확도 수치로 쓰지 않는다.
반복을 5회에서 행동별 1~3회로 줄인 이유(2026-10-21 제안, 10-22 결정): 빠른 점검판에서 틀린 원인이 전부 개인차(얼굴형·자세·자리)였다. 같은 사람이 반복하는 것보다 사람 수를 늘리는 것이 정확도 추정에 더 도움이 된다. 반복이 적으면 한 번 틀릴 때 정확도가 크게 움직이므로 사람 수(5명)로 보완한다.

## 3. 행동 표

**시작 전에 보정(정면·필기 자세·눈 감기)을 꼭 한다**(2026-10-16 결정). 졸음 판정은 보정했을 때만 동작하므로, 보정하지 않으면 시작 버튼이 꺼져 있다.

기준값은 `focusLogic.ts` 기준: 자리 이탈·엎드림 60초, 졸음 21초(정면·숙임 모두, 보정 기준), 다른 화면 즉시.
마감 = 기준 + 여유 5초. 다른 화면은 탭·앱을 바꾸는 동작 시간만 줘서 3초, 13번은 다른 탭으로 간 뒤 자리를 떠나는 시간을 더 줘서 70초다.

## 4. 진행 방식

1. `/tracking` 화면에서 "보정하기"로 보정한 뒤, "각본 시험 열기" → 빠른 점검판 / 정식판을 고른다.
2. 패널에 다음 행동 이름과 설명이 보인다. **스페이스바**를 누르면 그 행동이 시작되고, 행동 이름과 남은 시간이 크게 보인다.
3. 정해진 시간이 지나면 **삐 소리**(한 번)가 나고 그 행동이 자동으로 끝나 채점된다. 6번은 30초에 소리 두 번으로 돌아올 때를 알린다. 모든 행동이 끝나면 소리 세 번.
4. 행동 사이는 쉬는 시간이며 채점하지 않는다. 준비되면 다시 스페이스바.
5. 결과표가 행동이 끝날 때마다 바로 갱신된다. 모든 행동이 끝나면 0.1초 기록 CSV가 자동으로 내려받아진다.

- **부풀림을 막는 장치(2026-10-16)**: 행동 중에는 판정을 화면에 보여 주지 않는다(보면서 무의식적으로 맞추게 되므로). 패널에 "평소 하던 대로 하세요. 카메라를 의식해서 잘 보이게 하지 마세요."를 계속 보여 준다.
- **이어 하기**: 시험 순서와 채점 결과는 브라우저 저장소(`localStorage`, `scriptTest:v1`)에 저장한다. 새로고침하거나 정식판을 나눠 해도 다음 행동부터 이어서 한다. 보정은 저장하지 않으므로 이어서 할 때 다시 보정한다.
  - 저장된 시험이 예전 행동 표로 만들어져 새 행동이 없으면 안내와 함께 "새 행동 추가해 이어 하기" 버튼이 뜬다(정식판이면 `repeats`만큼 뒤에 붙임). (2026-10-22)
- **건너뛰기**: 행동 사이에 "이 행동 건너뛰기"를 누르면 다음 행동을 채점 없이 순서에서 뺀다. 특정 행동만 해 볼 때 쓴다. 정확도 분모에서도 빠진다. (2026-10-22)
- 다른 탭(9·13번)에 가 있어도 0.1초 기록과 채점은 워커 신호로 계속 돈다(`src/lib/workerInterval.ts`).

## 6. 채점

판정을 두 가지로 동시에 계산해 각각 채점한다.
- **가이드라인 없이**: `useFocusState(face, false, undefined, { body, baseline })` — 지금 실제 공부 화면(`StudyRunner`)과 같은 방식. 이것이 기준 결과다.
- **가이드라인 켬**: `useFocusState(face, false, pose, { body, baseline })` — 가이드라인을 공부 시간 측정에도 쓰면 정확도가 오르는지 보기 위한 비교.

행동 하나의 채점:
- 초록 행동: 행동 시간 동안 상태가 한 번이라도 `focus`가 아니면 오답.
- 노란불 행동: 처음 나온 노란불이 기대 상태이고 마감 안이면 정답. 다른 노란불이 먼저 나오거나 마감을 넘기면 오답. 걸린 시간도 기록.
- 시간: 행동 시작·끝 시점의 확정 `studyMs` 차이 = 실제로 들어간 시간. 공부로 들어가야 할 시간과 비교.

결과표:
- 요약: 전체 정확도, 필기 오판율(2·3번에서 노란불이 뜬 비율), 공부 시간 오차 = (들어간 시간 합 − 들어가야 할 시간 합) ÷ 들어가야 할 시간 합. 가이드라인 없이 / 켬 두 줄, 목표값과 함께.
- 행동별: 맞은 횟수/전체(없이·가이드), 회차별 처음 나온 노란불(원인 확인용), 노란불까지 걸린 평균 시간, 들어간 시간 vs 들어가야 할 시간.

가이드라인 결과를 실제 공부 화면에 쓸지는 이 비교 결과를 보고 정한다. 도움이 안 되면 쓰지 않는다.

**측정 집계 (2026-10-22)**: 모든 회차에서 0.1초 표본의 얼굴·눈 감음·휴대폰·고개 각도로 `Measure`를 계산해 결과에 저장한다(`measureOf`).
- 최장 연속: 얼굴 안 보임 / 눈 감음 / 휴대폰 잡힘. 같은 값이 이어진 구간의 길이 중 최대. 모름(빈칸)은 구간을 끊는다.
- 끊김: 안 보임 사이에 잠깐(끊김 내성 2초 이하) 보인 구간, 감음 사이에 잠깐(2초 이하) 뜬 구간의 횟수와 최장. 앞뒤가 모두 반대 값일 때만 센다(행동 처음·끝은 제외).
- 고개 변동 폭: 얼굴이 보인 표본만, 10초 창을 밀며 (최대−최소)의 최대, 도 단위.
- 측정표(`measureRows`): 행동별로 최장은 최대, 횟수는 합, 고개 변동 폭은 평균. 결과 CSV에도 측정 열 8개가 붙는다. 옛 결과(측정값 없음)는 측정표에서 빠진다.

## 9. 한계

- 빠른 점검판은 1회씩이라 문제 찾기용이고 정확도 수치가 아니다. 정식판도 행동마다 1~3회라 한 사람의 한 번이 크게 움직인다 — 그래서 사람 수(팀원 3명 + 팀 외 2명)로 본다.
- 측정 행동은 기준값을 **만드는** 값이라 각본 시험(3층 평가)의 원래 역할과 다르다. 측정값으로 기준을 바꾸면 그 뒤 정식판으로 다시 검증해야 한다(기준을 만든 데이터로 그 기준을 평가하지 않는다).
- **각본 시험의 정확도는 "정해진 13가지 행동에서의 판정 정확도"다. 실제 사용 정확도가 아니다.** 보고할 때 이 범위를 밝힌다.
  - 정답을 아는 사람이 카메라를 의식해 잡히기 좋게 행동하면 실제보다 높게 나온다. 그래서 행동 중 판정을 숨기고 "평소처럼" 안내하며, 만든 사람만이 아니라 다른 팀원도 하고, 정식판은 순서를 섞는다.
  - 그래도 남는 차이는 실제 사용의 오판 신고(#121)로 보완한다.
- 시험하는 사람이 정해진 동작을 정확히 했는지는 본인을 믿는다.
- 각본에 있는 행동만 잰다. 실제 공부의 다양한 행동은 현장 연구의 오판 신고로 보완한다.

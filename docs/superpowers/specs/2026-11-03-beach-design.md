# 캠빛 해변 설계

## 왜 하는가

광장과 캠퍼스에 이어 세 번째 바깥 공간을 만들어 세계관을 넓힌다. 바다를 보며 비치체어에 앉아 파도 소리를 들으면서 공부하는 곳이다. 지금까지의 공간과 분위기가 확실히 달라서, 사용자가 일부러 찾아가고 싶은 자리가 되는 것이 목적이다.

## 목표

- `/beach` 주소의 바깥 공간 **캠빛 해변**. 광장의 문으로 들어가고 전체 지도에 나온다.
- 바다, 모래사장, 야자수, 나무 산책로가 있는 풍경. 바다는 잔잔하게 움직인다.
- 바다를 바라보는 비치체어 24석. 파라솔 하나에 두 자리씩 12세트.
- 앉으면 공부를 시작할 수 있고, 집중 판정·기록·랭킹·레벨은 다른 곳과 같다.
- 해변에 있는 동안 파도 소리가 난다.
- 밤에 켜지는 조명: 파라솔마다 작은 전구, 산책로 줄 전구, 모래 위 횃불.

## 목표가 아닌 것

- 수영, 물에 들어가기, 낚시, 보트
- 가게, 건물, NPC, 음식 주문
- 조개 줍기 같은 수집이나 미니게임
- 해변 전용 집중 규칙
- `experiment` 반영. 서비스 전용이다

## 하면 실패인 것

- 바다나 조명 때문에 일반 노트북에서 30FPS 아래로 떨어진다.
- 파도 소리가 사용자가 끌 수 없거나 집중을 방해할 만큼 크고 단조롭다.
- 물 위를 걷거나, 경계 밖으로 나가거나, 파라솔·의자에 갇힌다.
- 공부 중 시야를 파라솔이 가려 바다가 안 보인다.
- 광장·캠퍼스의 화면이나 접속 인원 표시가 달라진다.
- 같은 자리에 두 사람이 앉는다.

## 사용자 흐름

1. 광장의 해변 문으로 들어가거나 전체 지도에서 간다. 산책로 끝에 도착하고, 앞에 모래사장과 바다가 보인다.
2. 걸어 다니면 다른 참여자가 보인다. 물 가까이 갈수록 파도 소리가 커진다.
3. 빈 비치체어 앞에서 E를 누르면 앉고 그 자리가 내 자리가 된다. 공부 중인 자리는 벤치·캠프파이어와 같은 방식으로 다른 사람이 앉지 못한다.
4. `공부 시작하기`로 공부한다. 1인칭 시점에서 바다를 바라본다.
5. 일어나면 자리를 놓는다. 나가는 문으로 광장에 돌아간다.

## 공간

- 광장·캠퍼스와 같은 바깥 공간 구조(`WorldConfig`, `PlazaLayout`)를 쓴다. 실시간 방과 접속 장소 이름은 해변 전용으로 따로 둔다.
- 앞에서부터 바다 → 젖은 모래 → 마른 모래 → 나무 산책로 → 야자수 순서.
- 사용자가 걸을 수 있는 곳은 물가까지다. 하늘, 시간대, 날씨(비·눈), 별은 다른 공간과 같다.
- 좌석은 모두 바다 쪽을 본다.

## 소리

- 기존 소리 구조(`src/space/ambience.ts`)에 파도를 추가한다. 시냇물처럼 소리 파일 없이 브라우저가 만든다.
- 파도가 밀려오고 빠지듯 천천히 커졌다 작아지고, 일정하게 반복되는 느낌이 나지 않게 한다.
- 물과의 거리에 따라 커진다. 앉아서 공부 중일 때도 난다.
- 기존 소리 조절과 켜고 끄는 설정을 따른다. 해변을 나가면 멈춘다.

## 조명

- 낮에는 꺼져 있고 밤에 켜진다. 기존 바깥 공간의 밤 판단을 그대로 쓴다.
- 파라솔 전구, 산책로 줄 전구, 횃불로 구성한다. 횃불은 살짝 흔들린다.
- 실시간 광원은 다른 바깥 공간과 비슷한 수로 제한하고, 나머지는 스스로 빛나는 재질과 빛 번짐 표현으로 처리한다.

## 데이터

- 해변을 공부 자리용 지점으로 DB에 추가하고 좌석 24개를 넣는 마이그레이션을 쓴다. `0038`(광장), `0043`(캠퍼스), `0057`(캠프파이어)과 같은 방식이고, 앉기는 기존 `sit_cafe_seat`를 쓴다.
- 파일 번호는 PR 직전 `develop`의 최신 번호 다음으로 확인한다. 서비스 DB에만 머지 전에 적용하고 실험 DB에는 실행하지 않는다.
- 공부 기록·랭킹은 기존 표와 함수를 그대로 쓴다.

## 제약

- 새 라이브러리를 추가하지 않는다. 소리·텍스처 파일 없이 코드로 만든다.
- 배치는 코드에 직접 쓰지 않고 JSON으로 관리한다. 기준값은 파일 위 이름 붙인 상수로 둔다.
- 계산은 순수 함수로 분리하고 Node로 검사한다.
- 웹캠 처리와 집중 판정은 건드리지 않는다.
- 일반 노트북 30FPS 이상, 트래킹 켠 착석 공부도 포함한다.

## 빌더가 정해도 되는 것

- 정확한 크기, 좌석 배치, 색, 바다 표현 방법
- 광장에서 해변 문을 놓을 자리 (기존 길과 건물을 막지 않을 것)
- 전체 지도에 표시하는 모양
- 파도 소리의 세부 파라미터

## 사용자가 정한 것과 Claude가 제안한 것

사용자가 말함: 세계관 확장으로 해변을 만든다, 파라솔과 비치체어, 거기서 공부, 파도 소리, 조명.

Claude가 제안하고 사용자가 동의함: 이름 캠빛 해변, `/beach`, 광장 문과 전체 지도, 바다·모래·야자수·산책로, 물 진입 불가, 24석(파라솔 하나에 두 자리), 키오스크 없이 빈자리에 앉기, 거리에 따른 파도 소리, 조명 구성, 수영·낚시·가게·건물 제외.

# 캠빛 중앙도서관 개편과 책 대여 설계

## 왜 하는가

캠빛 중앙도서관은 지금 칸막이 책상이 있는 공부 자리일 뿐이고, 책장은 장식이다. 도서관에서 실제로 책을 빌려 읽을 수 있으면 "온라인 스터디카페"의 공간이 살아나고, 교재가 없어도 앉아서 할 일이 생긴다. 건물도 네모 벽돌 건물 대신 도서관임이 한눈에 보이는 모습으로 바꾼다.

## 목표

- 도서관 외관을 둥근 석재 건물로 바꾸고, 내부도 원통으로 맞춘다.
- 저작권이 끝난 소설을 사서나 서가에서 빌리면 가방에 들어온다.
- 빌린 책은 어느 지점에서든 가방에서 꺼내 앱 안에서 읽는다.
- 대여 기간은 2주다.
- 읽는 시간은 평소처럼 공부를 시작해 과목 `독서`로 재고, 랭킹·레벨에 다른 공부와 똑같이 들어간다.

## 목표가 아닌 것

- 저작권이 남은 책, 외부 e북 서비스나 학교 도서관 연동
- 책 추천, 평점, 독후감, 친구와 책 공유
- 연체료 등 벌칙, 연장 버튼, 재고(한 권을 여러 명이 동시에 빌릴 수 있음)
- 2층 난간(첫 사진의 메자닌). 2D 이동 시점을 가릴 수 있어 이번에는 뺀다
- `experiment` 반영. 이 기능은 서비스 전용이다

## 하면 실패인 것

- 책을 펴 놓기만 해도 공부 시간이 쌓이는 것
- 책을 읽으려고 다른 탭이나 외부 사이트로 나가야 해서 `offscreen`이 되는 것
- 번역본이나 현대어 편집본처럼 권리가 남은 글이 들어가는 것
- 책장 장식 때문에 일반 노트북에서 30FPS 아래로 떨어지는 것
- 기존 도서관 규칙(다른 탭·휴대폰 금지, 방해금지 고정)이 사라지는 것

## 사용자 흐름

1. 캠퍼스에서 둥근 도서관으로 들어간다.
2. 분야 안내판이 달린 서가 앞에서 E를 누르면 그 분야의 목록이, 사서 앞에서 E를 누르면 전체 목록이 뜬다.
3. 책 옆의 `대여하기`를 누르면 가방에 들어간다.
4. B키로 가방을 열어 책을 꺼내면 읽기 창이 뜬다. 플래너처럼 어느 화면에서든 띄울 수 있다.
5. 자리에 앉아 `공부 시작하기`에서 과목 `독서`를 고르면 평소 판정 규칙대로 시간이 쌓인다. 졸거나 자리를 비우면 타이머가 멈춘다.
6. 가방에 `D-3`처럼 남은 날짜가 보이고, 먼저 반납할 수 있다. 2주가 지나면 자동으로 반납된다.

## 외관 (참고: IMG_4662)

참고 사진은 저장소에 올리지 않고 최원준의 컴퓨터에 있다: `~/Downloads/IMG_4662.JPG`(외관), `~/Downloads/IMG_4660.JPG`(내부).

- 밝은 석재의 원통 건물, 위쪽 띠, 입체 `LIBRARY` 글자, 가운데 큰 유리창, 유리문 두 짝, 문 앞 붉은 벽돌 길.
- 사진 양옆의 벽돌 날개 건물은 넣지 않는다. 지금 도서관의 시계탑도 뺀다.
- 지금은 `src/world/campus.json`의 도서관이 `Building`(상자)과 `CampusBuildingTrim`(시계탑·담쟁이)으로 그려진다. 도서관만 새 원통 모양으로 그리고, 부딪힘도 원통에 맞춘다.

## 내부 (참고: IMG_4660)

- 둥근 벽은 숨 라운지가 쓰는 `theme.round`(`RoundWall`, `roundWallBoxes`)를 다시 쓴다. 문과 곡선 벽을 맞추는 방법도 숨 라운지를 따른다.
- 실제 캠퍼스가 보이는 큰 창문, 격자 천장, 밝은 대리석 바닥(사용자가 화면을 보고 나무 바닥에서 변경), 흰 기둥, 큰 화분.
- 문으로 들어오면 사서 책상이 바로 보인다.
- 가운데에 긴 나무 책상, 빨간 의자, 스탠드. 좌석은 24석을 유지한다.
- 안쪽 절반에 책장을 방사형으로 세우고, 가운데를 보는 옆면에 분야 안내판을 단다.
- 지금 16×16 크기로 좁으면 넓혀도 된다(`rest` 지점이 아니므로 공부 자리 동선을 우선한다).
- 좌석을 옮기면 `seats` 표의 위치도 같은 값으로 고치는 마이그레이션을 넣는다. 좌석 번호는 바꾸지 않아 진행 중인 기록과 좌석 배정이 깨지지 않게 한다.

## 책장과 사서

- 책장은 분위기용이다. 책등이 빽빽한 모양으로 만들고, 실제 책과 일일이 연결하지 않는다. 책이 적어도 빈약해 보이지 않게 하려는 것이다.
- 서가 분야는 3개다: `한국 단편`, `한국 장편`, `시`. 외국 고전은 다음으로 미룬다.
- 서가의 E 입력은 게시판(`noteBoardSpot`)처럼 Player의 자리 목록에 끼워 받는다.
- 사서는 바리스타(`BaristaNpc`, `baristaLogic.ts`)나 교수 NPC(`professorLogic.ts`) 방식을 따른다. 책상 앞에 서면 인사하고 E로 전체 목록을 연다.

## 책 내용

- 처음에는 10권 안팎을 넣는다.
  - 한국 단편: 김유정 《봄봄》 《동백꽃》, 현진건 《운수 좋은 날》, 이효석 《메밀꽃 필 무렵》, 나도향 《벙어리 삼룡이》, 김동인 《감자》, 이상 《날개》
  - 한국 장편: 채만식 《태평천하》
  - 시: 윤동주, 김소월, 한용운의 시
- 각 책은 공유마당이나 위키문헌에서 받는다. 맞춤법만 고친 판본은 허용하고, 내용을 다듬었거나 해설이 붙은 판본, 출처가 불분명한 책은 넣지 않는다.
- 기준에 맞는 판본이 없는 후보는 뺀다.
- 책마다 출처 주소, 출처의 이용 조건, 작가 사망 연도를 표로 정리한다. 머지 전에 최원준이나 팀원이 이 표를 확인한다.
- 서비스를 외부에 널리 공개하기 전에 이 표로 한국저작권위원회 상담을 받는다. 지금 머지를 막는 조건은 아니다.
- 본문은 앱에 포함하되, 처음 읽을 때 받도록 책마다 파일을 나눠 초기 로딩을 늘리지 않는다.

## 대여 데이터

- 새 표 하나에 내 대여 기록을 둔다(사용자, 책 ID, 빌린 시각, 반납 기한, 반납 시각, 읽던 위치). 책 목록은 코드 쪽 데이터이고 DB에 넣지 않는다.
- RLS로 본인 것만 읽고 고친다. 게스트(익명 로그인)도 플래너처럼 쓸 수 있다.
- 반납 기한은 DB에서 정한다(빌린 시각 + 14일). 같은 책을 동시에 두 번 빌리지 못하게 한다.
- 기한이 지난 기록은 읽을 때 반납된 것으로 취급한다. 다시 빌릴 수 있다. 기한을 넘겼어도 이미 진행 중인 공부 시간은 끊지 않는다. 읽던 창도 그 공부가 끝날 때까지 그대로 둔다.
- 마이그레이션은 머지 전에 서비스 DB에 적용하도록 육심호에게 요청한다. 실험 DB에는 실행하지 않는다.

## 빌더가 정해도 되는 것

- 폴더는 `src/library/`, 대여 판정 같은 계산은 순수 함수(`libraryLogic.ts`)로 둔다.
- 읽기 창의 쪽 나눔, 글꼴 크기, 창 모양은 앱 안의 플래너 창 스타일에 맞춘다.
- 동시에 빌릴 수 있는 권수 상한(제안: 5권).
- 책장 그리기 방식. 여러 물체를 한 번에 그리는 방법을 써서 FPS를 지킨다.
- 공부 시작 창에서 `독서` 과목이 없을 때 쉽게 만들도록 돕는 방식(제안: 책을 빌린 사용자에게 `독서` 칩을 제안).
- 원통 크기와 캠퍼스 안 정확한 위치. 주변 건물·길과 겹치지 않아야 한다.

## 제약

- 라이브러리를 새로 추가하지 않는다. 필요해지면 먼저 묻는다.
- 지점 배치는 `src/space/branches/cambit-library.json`에 둔다.
- 기준값은 파일 위쪽 이름 붙인 상수로 둔다.
- 화면 동작은 개발 서버에서 눈으로 확인한다: 외관, 내부 이동·부딪힘, 2D→3D 전환, 대여부터 읽기까지, 공부 시간 기록과 랭킹 반영.

## 사용자가 정한 것과 Claude가 제안한 것

사용자가 정함: 사서·서가 대여, 가방 보관과 다른 지점에서 읽기, 2주 대여, 랭킹·레벨 포함, 원통 내외관, 사진 스타일, 서가는 분야별·사서는 전체 목록, `공부 시작하기` + `독서` 과목 방식, 3개 분야 10권 안팎, 맞춤법만 고친 판본 허용 기준.

Claude가 제안하고 사용자가 지나가며 동의함: 자동 반납과 벌점 없음, 방사형 책장, 2층 난간 제외, 날개 건물 제외, 24석 유지.

Claude가 정함(문서 확인 때 바꿀 수 있음): 빌릴 수 있는 권수 5권, `독서` 과목 제안 칩, 외부 공개 전 상담을 머지 조건으로 두지 않음.

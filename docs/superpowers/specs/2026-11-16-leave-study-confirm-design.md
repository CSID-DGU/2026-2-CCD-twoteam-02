# 공부 중 떠날 때 확인 통일 (짧은 설계, #558)

- 작성: 최원준, 2026-11-16
- 브랜치: `fix/wonjun/leave-study-confirm` (base `develop`)

## 왜

공부 중에 자리를 떠나는 경로마다 확인을 묻는지가 달랐다(#558). 부름 가기·회의 참가·따라가기는 묻고, 메뉴 "캠리단길로"·E로 일어나기·로그아웃은 바로 끝냈다. 실수로 공부가 끊기지 않게 **공부 중이면 전부 묻는 것**으로 통일한다(사용자 결정).

## 정한 것

- 묻는 기준: 공부 세션이 도는 동안(`useMyStudying()`, 공부 시작 창에서 시작한 뒤 ~ 끝날 때. 중지 중 포함). 앉았지만 시작 전·서 있을 때는 묻지 않는다.
- 문구: 모두 **"공부를 끝낼까요?"**. 기존 "공부를 끝내고 갈까요?"·"공부를 끝내고 회의로 갈까요?"도 바꾼다.
- E로 일어나기: **확인 창**을 띄운다(사용자 결정. E 두 번 누르기 대신). [끝내기] [계속 공부하기], Esc 는 계속 공부하기.
- 메뉴 "캠리단길로"(캠빛 대학교로)·"트래킹 검증"·로그아웃(메뉴, 계정 설정의 "로그인하러 가기"): 같은 확인 창.
- 부름 [가기]·회의 [참가]·[따라가기]: 지금처럼 그 줄 안에서 묻고 문구만 바꾼다(채팅 로그 줄이라 창을 띄우지 않음).
- 적용: 지점(BranchScene)과 바깥 공간 벤치·캠프파이어·빈백·비치체어(WorldScene). 둘 다 같은 Player 를 쓴다.

## 하지 않는 것

- 탭 닫기·새로고침(브라우저 확인 창이 필요해 범위 밖).
- 공부 시작 전이나 쉬는 자리(빈백 쉬기·휴식방)에서 일어나기.

## 만드는 것

1. `src/study/EndStudyConfirm.tsx`: 확인 창 하나(`공부를 끝낼까요?`, 지금까지 공부한 시간은 기록에 남는다는 한 줄, [끝내기] [계속 공부하기]). 키오스크 확인 창과 같은 모양.
2. `src/space/Player.tsx`: 새 prop `confirmStand?: RefObject<(() => void) | null>`, `standRef?: RefObject<boolean>`. 앉아서 E 를 눌렀을 때 confirmStand 가 있으면 일어나지 않고 그것을 부른다. standRef 가 true 가 되면 다음 프레임에 일어난다(확인 창의 [끝내기]).
3. BranchScene·WorldScene: 공부 중일 때만 confirmStand 를 채우고, 창이 떠 있는 동안 frozen.
4. SceneMenu·LogoutButton·AccountSettings: 공부 중이면 누를 때 확인 창을 거친다.
5. ChatOverlay·FollowButtons: 문구만.

## 확인

`npm run lint`, `npm run build`, 개발 서버에서 공부 시작 → E / 캠리단길로 / 트래킹 검증 / 로그아웃 각각 확인 창 → 계속 공부하기면 그대로, 끝내기면 끝나고 기록 저장. 시작 전에는 바로 일어남.

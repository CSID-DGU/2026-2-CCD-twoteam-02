# 월드 별자리와 오늘의 별자리 운세 — 설계 (2026-10-30, 같은 날 사용자 피드백으로 다시 설계)

관련 Issue: #321. 앞 단계: #316 하늘과 시간(`docs/superpowers/specs/2026-10-30-world-sky-design.md`).
대상 브랜치: `develop` (`feat/hyun/constellation`). **DB 변경 있음**(14절). 새 라이브러리·외부 서비스·외부 이미지 없음.

## 1. 왜

#316 의 밤하늘에 황도 12궁 별자리를 그리고, 별자리를 누르면 오하아사처럼 "오늘의 별자리 운세"(12별자리 순위와 한 줄 운세)를 보여 준다. 가입할 때 생일(월·일)을 받아 **내 별자리**를 하늘에서 금색으로 보여 주고, 운세 창 맨 위에 내 별자리 운세를 자세히 보여 준다. 목적은 서비스 분위기와 재미.

## 2. 다시 설계한 이유 (사용자 피드백, 2026-10-30)

처음 설계(실제 하늘 위치 + 남쪽에 이번 달 별자리 금색)를 화면에서 보니:
- 실제 위치는 어떤 별자리가 왜 거기 있는지 알기 어렵고, 계절에 따라 별자리가 지평선 아래라 안 보인다.
- 마우스를 잠그려고 하늘을 누르면 별자리가 눌려 운세 창이 뜬다.
- 별자리에서 먼 하늘을 눌러도 눌린다(클릭 판이 넉넉해서).
- 누른 별자리가 맨 위 카드로 나오는데, 정작 궁금한 건 **내 별자리**다. 목록의 다른 별자리는 자세히 볼 방법이 없다.

## 3. 목표 · 하지 않는 것 · 실패로 치는 것

목표 (사용자 결정)
- **머리 위 12달 원**: 고개를 들면 머리 위를 둘러싼 원(고도 40°)에 12별자리가 30° 간격으로, 북쪽부터 시계 방향으로 1월~12월 순서. 별자리 모양은 그대로 두고 크기를 비슷하게 맞춘다. 아래에 늘 이름표("물고기자리"(달은 안 적음: 별자리 날짜가 달과 딱 맞지 않음)).
- 밤(별 투명도 `stars`)에만 보인다. 해·달·밤은 #316 처럼 실제 시각을 따른다.
- **내 별자리 금색**: 생일(양력 월·일)로 정한 내 별자리만 금색으로 반짝인다. 생일이 없으면 금색 없음.
- **누르기**: 마우스가 잠긴 상태에서 조준점이 별자리 별·선에서 약 3° 안쪽일 때 클릭하면 운세 창. 잠기지 않은 상태의 클릭은 잠그기만 한다.
- **운세 창**: 어느 별자리를 눌러도 같은 창. 맨 위는 **내 별자리 카드**(순위·한 줄 운세·행운의 공부 시간·과목). 생일이 없으면 그 자리에 "생일을 넣으면 내 별자리 운세를 볼 수 있어요"와 생일 넣는 칸. 아래 1~12위 목록은 줄을 누르면 펼쳐져 행운의 시간·과목이 보인다(다시 누르면 접힘). 누른 별자리 줄은 처음부터 펼쳐 둔다.
- **생일 받기**: 회원가입 화면에 생일(월·일) 칸(선택 항목). 이미 가입한 사람은 내 프로필(계정 탭)과 운세 창에서 넣는다.
- 생일은 **월·일만** 저장하고 **본인만** 볼 수 있다(태어난 해는 받지 않음).
- 운세는 우리가 만든 순위·문구(진짜 오하아사 아님), 같은 날 모두 같은 순위, 서울 자정에 바뀜. 밤에만.

하지 않는 것
- 실제 하늘 위치 계산(항성시)과 "이번 달 별자리" 금색. (처음 설계에서 뺌)
- 다른 사람의 별자리 보기, 생일 축하, 태어난 해 저장.
- 진짜 오하아사 가져오기, 낮에 운세 보기.
- experiment 브랜치·실험 계정 변경.

실패로 치는 것
- 밤에 12별자리 중 하나라도 안 보이거나 이름표가 겹쳐 읽을 수 없는 것.
- 마우스를 잠그려는 클릭이나 별자리에서 먼 하늘 클릭에 운세 창이 뜨는 것.
- 생일이 다른 사람에게 보이는 것.
- 같은 날 사람마다 순위가 다른 것, 30FPS 아래.

## 4. 원 배치 계산 (`src/world/starLogic.ts`, 순수 함수)

- `RING = { altitude: 40°, size: 12° }`: 별자리마다 가운데를 고도 40°, 방위 (달 − 1) × 30°(북 0·동 90°)에 둔다.
- 모양: 별자리 별들의 평균 방향을 가운데로 잡고 접평면(동·북)에 펼친 뒤, 가장 먼 별까지가 `size / 2`가 되게 크기를 맞춰 원 위 자리의 접평면에 올린다. 별자리의 북쪽이 머리 위(천정) 쪽을 보게 둔다.
- `ringLayout() → { id, month, center: Vec3, stars: Vec3[], label: Vec3 }[]`: 12개. 이름표 자리는 가운데에서 `size / 2 + 2°` 아래(고도가 낮은 쪽).
- `pickRingSign(ray: Vec3, layout) → id | null`: 조준점 방향과 각 별자리 별·선(선분)의 가장 가까운 각도가 3° 이하인 별자리 중 가장 가까운 것.
- `signOfBirthday(month, day) → id`: 5절 날짜표.

## 8. 그리기 (`src/world/Constellations.tsx`, WorldSky 안)

- 12별자리를 `ringLayout()` 자리에(반지름 330): 점(별) + 선. 보통은 흐린 하늘색(선 투명도 0.45 × 별 투명도), 내 별자리는 금색(`#ffd27a`) 반짝임(±20%, 2초).
- 이름표: 별자리마다 "물고기자리"(달은 안 적음: 별자리 날짜가 달과 딱 맞지 않음)(캔버스 글자판, 카메라를 봄). 내 별자리는 금색 글자.
- 모두 하늘 레이어(2)·음수 그리는 순서(#316 규칙). 점·선은 위치가 고정이라 화면 밖 판정(경계 구)을 처음 한 번 계산.
- 클릭 판은 두지 않는다.

## 9. 누르기

- 마우스가 잠긴 상태(1인칭)의 클릭만. 별 투명도 > 0.5 일 때만.
- 조준점 방향으로 `pickRingSign`(3° 이하). 별자리 앞을 건물·캐릭터가 가리면(장면 레이어 0 광선이 1m 너머 보이는 물체를 먼저 맞힘) 무시. 캐릭터는 지금처럼 프로필 창.
- 잠기지 않은 상태의 클릭은 잠그기만 하고 별자리는 반응하지 않는다.

## 10. 운세 창 (`src/world/FortunePanel.tsx`)

- 제목 "✦ 오늘의 별자리 운세 · 10월 30일".
- 맨 위: 내 별자리 카드(순위·한 줄 운세·행운의 공부 시간·과목). 생일이 없으면 안내 + 월·일 고르기 + 저장 버튼(저장하면 바로 카드가 보이고 하늘의 금색도 바뀜).
- 아래: 1~12위 목록. 줄을 누르면 펼침/접음(행운의 시간·과목). 누른 별자리 줄과 내 별자리 줄은 강조, 누른 별자리 줄은 처음부터 펼침.
- 창이 떠 있는 동안 캐릭터·시점·감정표현·메뉴 단축키·V 를 막는다. Esc·닫기·바깥 누르기로 닫는다.

## 13. 성능

점 약 110개·선 약 100개·이름표 12장(위치 고정). 클릭할 때만 광선 계산. 30FPS 영향 거의 없음.

## 14. DB (`supabase/migrations/0035_birthday.sql`)

- `profiles`에 `birth_month smallint`(1~12), `birth_day smallint`(1~31) 추가. 둘 다 비었거나 둘 다 있어야 함(check). 날짜가 그 달에 있는지(예: 2/30 안 됨)도 check (2월은 29일까지).
- `profiles`는 이미 **본인만 읽고 고칠 수 있다**(0004 RLS). 다른 사람이 보는 `avatars` 뷰는 `id, nickname, avatar`만 고른다 → 생일은 남에게 안 보인다. 뷰는 고치지 않는다.
- 가입 트리거 `handle_new_user`를 다시 만들어 `raw_user_meta_data`의 `birth_month`·`birth_day`가 올바른 숫자면 같이 넣는다. 틀린 값이면 비워 둔다(가입은 막지 않음). 닉네임 처리는 그대로.
- 적용: develop 으로 가는 PR 이라 **머지 전에 서비스 DB 에 실행**(김현이 SQL Editor 에서 직접). experiment DB 에는 실행하지 않는다.

## 15. 확인 방법

Node (스크래치패드 검사 스크립트)
- `ringLayout`: 12개, 가운데 고도 40° ± 0.5, 방위가 달 순서로 30° 간격(1월 북쪽), 별자리마다 가장 먼 별까지 6° ± 0.5, 이름표가 가운데보다 아래
- `pickRingSign`: 각 별자리 첫 별 방향이면 그 별자리, 별·선에서 5° 떨어지면 null, 두 별자리 사이 빈 하늘은 null

- 운세: 처음 설계의 검사 그대로(같은 날 같은 순위, 1~12, 서울 자정에 바뀜, 문구 구간)
- lint·build

화면 (사용자, 로그인 필요): `?time=22:00` 머리 위 12달 원·이름표·내 별자리 금색 / 잠근 뒤 별자리 클릭 → 창(맨 위 내 별자리, 줄 펼치기) / 잠그기 클릭에는 안 뜸 / 먼 하늘 클릭에는 안 뜸 / 가입 화면 생일 칸, 계정 탭 생일 바꾸기 / 다른 계정에서 내 생일이 안 보임

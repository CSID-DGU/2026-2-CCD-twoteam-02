# 캠빛 대학교 캠퍼스 — 설계 (2026-10-31)

대상 브랜치: `develop` (`feat/wonjun/cambit-campus`). 새 라이브러리 없음. experiment 브랜치는 바꾸지 않는다.
관련: 광장 월드 #315(`src/world/`), 지점 테마 #57, 휴식방 숨 라운지(rest 지점), 공부 중지 #236.

## 1. 왜

지금 광장 옆에 두 번째 바깥 공간으로 **대학교 캠퍼스**를 만든다. 아이비리그가 떠오르는 화사하고 감성 있는 미국 대학 느낌이다.
캠퍼스 건물은 모두 공부하는 곳이지만, **어떻게 공부하는가**로 건물마다 성격을 나눠 골라 가는 재미를 준다. (사용자 결정, 2026-10-31)

## 2. 목표 · 하지 않는 것 · 실패로 치는 것

목표
- 지금 광장에서 길을 따라 걸어가 큰 정문을 지나면 캠퍼스로 넘어간다.
- 캠퍼스 가운데 잔디 안뜰(쿼드)에 돗자리·빈백이 있고 실제로 앉아 쉴 수 있다(기록 없음, 다른 사람에게 앉은 모습이 보임).
- 건물 다섯 채, 들어가면 지금 지점처럼 실내 화면으로 바뀐다. 건물마다 공부 방식이 다르다(4절).
- 강의실은 실제 시계 기준 공동 시간표(매시 50분 수업 · 10분 쉬는 시간)로 다 같이 공부하고 쉰다.

하지 않는 것
- **화면 공유**(학생회관 카페에서 하자는 안): 영상을 다른 사람에게 보내는 일이라 팀 절대 규칙("서버로 보내는 것은 수치 데이터뿐")과 부딪혀, **팀 결정 뒤에 따로** 한다. (사용자 결정)
- 실험실(어울리지 않아 정보관으로 바꿈, 사용자 결정).
- 캠퍼스와 광장을 한 화면에 이어 붙이기(크기·FPS 때문에 정문에서 화면을 바꿈).
- 외부 3D 모델·그림 파일(모두 상자·원기둥·잎 판 등 코드로 그림, 지금 소품 방식).
- 키오스크(모든 건물이 카페 방식: 빈자리에 앉으면 내 자리).

실패로 치는 것
- 일반 노트북에서 캠퍼스가 30FPS 아래로 떨어지는 것(덩굴 잎·나무가 많아질 수 있음 → 인스턴싱).
- 정문·건물을 드나들 때 엉뚱한 자리나 방향에 서는 것(광장 건물 드나들기와 같은 규칙).
- 도서관·정보관의 고정 설정을 공부 시작 창에서 바꿀 수 있는 것.
- 강의실 쉬는 시간 자동 멈춤이 끝나도 공부가 다시 이어지지 않는 것, 또는 쉬는 시간에도 기록이 쌓이는 것.

## 3. 이름 · 모양 (사용자 결정)

- 이름: **캠빛 대학교**. 현판에 "캠빛 대학교", 작게 "CAMBIT UNIVERSITY"(설계자 판단).
- 분위기: 붉은 벽돌 건물, 흰 창틀·기둥, 담쟁이덩굴, 초록 잔디, 시계탑. 화사한 낮 하늘(광장의 하늘·시간·날씨 #316·#317 이 있으면 같이 쓴다).
- 정문: 담쟁이로 대부분 덮인 벽돌 기둥 두 개 + 철제 아치 + 아치에서 늘어지는 덩굴 줄기 + 기둥 아래 풀숲. 잎은 동그라미가 아니라 **뾰족한 담쟁이 잎 모양**(사용자 요구). 3D 에서는 잎 모양 판을 여러 장 겹쳐 그린다.
- 브레인스토밍 시안: 배치 A(가운데 쿼드형), 정문 A(담쟁이 벽돌 기둥).

## 4. 배치 (가운데 쿼드형, 사용자 결정)

위가 북쪽. 정문은 남쪽.

```
            [ 📚 도서관 · 시계탑 ]
   [🖥 정보관]    쿼드(잔디)     [🏛 강의동]
                돗자리·빈백
 [☕ 학생회관 카페]  ┃정문┃  [🌳 학생 라운지]
```

- 캠퍼스도 광장처럼 배치를 JSON(`campus.json` 등, 광장 `world.json` 과 같은 모양)으로 두고 화면 코드는 읽기만 한다.
- 광장에서 가는 길: 광장 남서쪽 모서리(지금 비어 있는 쪽)에서 길이 나가고 "캠빛 대학교 →" 표지판, 길 끝(광장 가장자리) 정문 앞에서 E → 캠퍼스 화면. (설계자 판단)
- 캠퍼스에서 정문(안쪽)으로 나오면 광장의 그 길 끝, 캠퍼스를 등지고 선다.
- 건물 입구는 모두 쿼드 쪽을 본다(광장 건물처럼 90도 단위 facing).

## 5. 건물 다섯 채 — 공부 방식 (사용자 결정)

| 건물 | 성격 | 다른 점 |
|---|---|---|
| 📚 도서관 | 조용히 혼자 몰입 | 칸막이 개인석, 높은 서가·큰 창·초록 독서등. **다른 탭·앱 사용함 끔, 휴대폰·학습기기 사용함 끔으로 고정**. 방해금지 고정·내 감정표현 끔(아래) |
| 🏛 강의실 | 다 같이 같은 시간표 | 계단식 좌석이 칠판을 봄. 칠판에 공동 시간표(6절) |
| 🖥 정보관 (컴퓨터실) | 인강·코딩·노트북 | 줄지은 컴퓨터 책상·모니터. **다른 탭·앱 사용함 켬, 휴대폰·학습기기 사용함 켬으로 고정** |
| ☕ 학생회관 카페 | 친구와 같이, 조금 시끌벅적 | 큰 테이블에 여럿이 앉음. 채팅·감정표현이 잘 보이는 곳(일반 카페 지점과 같은 규칙) |
| 🌳 학생 라운지 | 쉬는 곳 | 숨 라운지처럼 누워 쉬기만, 기록 없음(`rest`) |

- 도서관의 조용함 (사용자 결정, 2026-10-31):
  - 도서관 안에 있는 동안 **방해금지(#216)를 켠 채로 고정**해 끌 수 없게 한다. 귓속말·회의 초대 알림은 뜨지 않고, 나가서 볼 수 있다(지금 방해금지와 같음).
  - 채팅 창 자체는 열어 읽을 수 있다(숨기지 않음).
  - **내 감정표현 바퀴·단축키를 끈다.** 다른 사람의 감정표현은 지금처럼 보인다.
- 고정 설정은 공부 시작 창에 "이 건물은 ○○ 규칙이에요"로 보여 주고 바꿀 수 없게 한다. 설정은 지점 JSON 에 적는다(예: `rules`).
- 실내는 지금 지점처럼 16×16m 방 + 테마(`theme`), 출입문은 남쪽 벽. 캠퍼스 분위기(벽돌·흰 창틀·원목)에 맞춘다. 회의실은 두지 않는다(설계자 판단).
- DB: 건물마다 지점(`branches`, kind `cafe`)과 좌석을 넣는 마이그레이션 1개(번호는 그때 마지막 다음). 좌석 수는 빌더가 정함(지금 지점처럼 12~24).

## 6. 강의실 공동 시간표 (사용자 결정)

- **실제 시계(한국 시간) 기준, 모두 같은 시간표**: 매시 정각~50분 수업, 50분~정각 쉬는 시간. 서버가 시간을 맞출 필요 없음.
- 칠판: "2교시 · 남은 시간 23분" / "쉬는 시간 · 7분". 교시는 그날 몇 번째 시간인지(설계자 판단: 0시부터 센 시각 + 1).
- 쉬는 시간이 되면 화면에 "🔔 쉬는 시간이에요" 알림이 잠깐 뜬다(축하 카드처럼 누를 것 없음).
- **쉬는 시간에는 타이머·기록만 잠깐 멈추고, 사용자는 자유롭게 쉰다** (사용자 결정, 2026-10-31):
  - 지금의 "공부 중지"(#236)를 그대로 쓰지 않는다. 그건 캐릭터를 얼리고 나가기 버튼을 숨기고 "다시 시작" 버튼을 띄워서, 쉬는 시간에 맞지 않는다. 따로 **"쉬는 시간 멈춤"** 상태를 둔다.
  - 쉬는 시간 멈춤 동안: 타이머·기록이 쌓이지 않음, "다시 시작" 버튼 없음(눌러서 기록을 쌓을 수 없음), 캐릭터는 얼지 않아 일어나 쿼드·라운지로 가거나 나갈 수 있음.
  - 앉아서 공부 중이던 사람은 수업 시작에 자동으로 이어서 공부한다(웹캠·판정을 다시 켬). 표시등은 쉬는 시간 동안 "쉬는 시간"(설계자 판단: 표시 없음과 같은 모양).
  - 쉬는 시간에 앉아 공부를 시작하면 "다음 수업부터 기록돼요"로 멈춘 채 시작했다가 수업 시작에 이어 간다.
  - 사용자가 직접 "공부 중지"를 눌러 둔 상태는 그대로 사용자가 푼다(수업 시작에 자동으로 풀지 않음). 두 멈춤은 따로 기억한다.
- 시간표 계산(지금 시각 → 수업/쉬는 시간, 교시, 남은 분)은 순수 로직으로 두고 Node 로 검사한다.

## 7. 쿼드의 돗자리·빈백 (사용자 결정: 앉을 수 있게)

- 체크무늬 돗자리, 알록달록한 빈백. 앉으면 기록 없이 쉬기만(휴식방과 같음). 다른 사람에게 앉은 모습이 보인다.
- 캠퍼스는 바깥 공간(광장 화면 계열)이라, 지금 광장의 "건물 입구 = Player 의 앉는 자리" 방식에 쉬는 자리를 더한다. 실시간 위치 메시지의 `seat` 로 어느 자리에 앉았는지 보낸다.
- 바깥 자리라 DB 자리 잡기는 하지 않는다(두 사람이 같은 빈백에 앉으면 겹쳐 보여도 받아들임). (설계자 판단)

## 8. 실시간 · 지도

- 캠퍼스는 광장과 **다른 실시간 방·접속 장소 이름**(예: `campus`)을 쓴다. 친구 목록의 있는 곳 이름 "캠빛 대학교".
- 전체 지도(G): 캠퍼스에 있으면 캠퍼스 배치를 그린다(광장 지도와 같은 방식). (설계자 판단)
- 꽃 피는 칭호 리본·채팅·감정표현·오른쪽 위 메뉴·캐릭터 숨김 모드는 광장과 같이 동작한다.

## 9. 단계 (설계자 판단)

1. 캠퍼스 월드: 광장 길·표지판·정문(양쪽), 캠퍼스 배치·쿼드·건물 겉모습, 돗자리·빈백 앉기, 실시간 방·지도
2. 건물 실내 다섯 곳과 건물별 규칙(고정 설정, rest), 마이그레이션
3. 강의실 공동 시간표와 쉬는 시간 자동 멈춤

단계마다 따로 계획·구현·PR 한다.

## 10. 빌더에게 맡기는 것

- 파일·폴더 이름, 캠퍼스 크기(광장보다 작거나 비슷하게, 성능 목표 안), 건물 겉모습 크기·높이, 실내 좌석 배치와 좌석 수.
- 덩굴 잎·나무 그리는 방법(인스턴싱 권장).
- 공부 시작 창에 고정 규칙을 보여 주는 문구 모양.

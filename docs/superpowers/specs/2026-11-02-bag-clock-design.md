# 가방 속 시계: 스톱워치 + 알람 (설계)

- 날짜: 2026-11-02
- 담당: 최원준
- 대상 브랜치: `develop` (서비스). 실험(`experiment`)과 무관
- 관련: 가방·플래너 #385, 노트 넘기기 #394 (같은 가방·창 구조)

## 1. 왜

가방(B)에는 스터디 플래너와 메모장이 있다. 여기에 **시계**를 하나 넣어, 공부하다가
- 문제 하나 푸는 시간을 재고(스톱워치),
- "40분 뒤에 쉬자"나 "3시 30분"처럼 직접 맞춘 때에 알림을 받고(알람)

싶다(사용자). 시계는 **예쁘게, 파스텔 톤에 질감 있게** 생겨야 한다(사용자). 꺼내 쓰고 싶은 물건이어야 한다.

## 2. 목표 / 하지 않을 것 / 실패로 보는 것

**목표**
1. 가방에 "시계"가 생기고, 꺼내면 화면에 띄워 두는 창(플래너처럼)이 된다.
2. 스톱워치: 시작·멈춤·초기화.
3. 알람: **몇 분 뒤**(남은 시간이 줄어듦)와 **시각**(예: 15:30) 두 방식.
4. 알람이 울리면 알람 소리 + 시계 흔들림 + 화면 가운데 끄기 창.

**하지 않을 것**
- 구간 기록(랩), 알람 여러 개, 반복 알람(매일).
- 계정 저장(DB). 이 브라우저에만 기억.
- 집중 판정·공부 타이머(초록불)와 연결. 시계는 개인 도구일 뿐 공부 시간 기록에 영향 없음.
- 소리 파일, 새 라이브러리.

**실패로 보는 것**
- 다른 탭에 가 있거나 시계를 닫아 둬서 알람이 늦게 울리거나 안 울린다.
- 새로고침·화면 이동(로비↔지점↔기록)으로 재던 시간이 사라진다.
- 소리가 브라우저에 막혀 조용한데 알 수 없다.
- 밋밋한 위젯처럼 보인다(파스텔·질감이 없음).

## 3. 정해진 것 (사용자 결정)

### 3.1 모양: A. 민트 회중 스톱워치
- 둥근 **민트** 몸통(밝은 쪽 #d9f2e6 → #8fcab2 그라데이션), **크림색 판**(#fffaf0 → #f4ead9), 위에 **분홍 꼭지**(#f6c9d4 → #e9a9b9), 옆에 작은 분홍 버튼.
- **도자기·종이 같은 질감**: 아주 옅은 잡티(SVG 노이즈, 플래너 종이와 같은 방식) + 둥근 볼록함(안쪽 그림자·하이라이트).
- 판 숫자는 둥근 글꼴, 진한 회청색(#4a4f63). 큰 숫자(분:초 또는 시:분:초) + 작은 숫자(1/100초는 스톱워치만).
- 시안: 브레인스토밍 화면(`.superpowers/brainstorm/…/stopwatch-look.html`, 저장소 밖)의 A. 창 전체 배치는 `clock-layout.html`(사용자 확인).

### 3.2 스톱워치
- **꼭지를 누르면 시작, 다시 누르면 멈춤.** 초기화 버튼.

### 3.3 알람
- **몇 분 뒤**: 분을 정하면 판에 남은 시간이 거꾸로 줄어듦.
- **시각**: 시:분을 정하면 그 시각에 울림(이미 지난 시각이면 다음 날 그 시각).
- 울릴 때: **알람 소리**(직접 맞춘 알람이라 알람 소리여도 괜찮음).
- **"소리 끔"이나 "방해금지"가 켜져 있어도 울린다** (직접 맞춘 알람이니까).

## 4. 제가 정한 것 (사용자 확인 전 기본값)

### 4.1 창과 가방
- 가방 패널에 "시계" 칸(작은 시계 그림 + "꺼내기/넣기"), 플래너와 같은 방식. 꺼냄 여부는 이 브라우저에 기억(`dooteum.clock.open`).
- 창은 `FloatingWindow`(손잡이 끌어 옮김, 자리 기억 `id="clock"`). 손잡이 줄에 "⏱ 시계", 탭 [스톱워치 | 알람], ✕(넣기). **손잡이 줄 색은 플래너의 남색(#3f5d73)이 아니라 시계 몸통에 맞춘 민트**(예: 바탕 #8fcab2, 글자 진한 초록 #2f5d4c, 고른 탭은 크림 #fffaf0) (사용자: 위 줄만 색 맞추면 됨). 창 배치는 `clock-layout.html` 시안 그대로(사용자 확인).
- 시계 본체 크기 약 180px. 창 전체가 작게(로비·지점 화면을 덜 가리게).

### 4.2 스톱워치 동작
- 표시: 1시간 미만 `MM:SS` + 작은 `.cc`(1/100초), 1시간 이상 `H:MM:SS`.
- 꼭지 = 시작/멈춤, 옆 분홍 버튼 = 초기화(멈춘 상태에서만 눌림).
- 구간 기록은 없음.

### 4.3 알람 동작
- 한 번에 **하나만**. 새로 맞추면 이전 알람은 사라짐. 맞춘 알람은 판 아래 작게 "⏰ 15:30" 또는 "⏰ 40분 뒤 (15:30)".
- 몇 분 뒤: 1~600분. 빠른 버튼 5·10·25·40·50분 + 직접 입력. 판에 남은 시간 `MM:SS`(1시간 이상 `H:MM:SS`).
- 시각: `<input type="time">`. 이미 지난 시각이면 다음 날.
- 알람 취소 버튼.
- **스톱워치와 알람은 동시에 돌아갈 수 있다.** 판에는 고른 탭의 것을 크게, 다른 쪽이 돌고 있으면 판 아래 작게.

### 4.4 계속 돌아가기
- 시각 기준으로 저장: 스톱워치는 `시작 시각 + 쌓인 시간`, 알람은 `울릴 시각(ms)`. 매 틱마다 더하는 방식 아님(늦어져도 틀리지 않게).
- 상태는 **localStorage**에 **계정별 키**(`dooteum.clock.<사용자 id>`)로 저장 → 새로고침·화면 이동·시계 닫기에도 이어짐. 계정을 바꾸면 다른 사람의 알람이 울리지 않음.
- 한계(제 판단, 받아들임): 로그아웃 중·로그인 화면·"여기서 계속하기"로 넘긴 탭(#347 탭 양보)에서는 감시하지 않는다. 같은 브라우저의 다른 탭이 이어받으면 그 탭이 같은 키를 읽어 울린다. 다른 기기로는 넘어가지 않는다(브라우저에만 기억하므로).
- 알람 감시는 시계 창이 닫혀 있어도 돌아야 하므로 **가방(BagLayer, 로그인 화면 어디서나 깔림)** 쪽에서 한다.
- 숨긴 탭에서도 늦지 않게 `src/lib/workerInterval.ts`(1초 신호)로 확인. 새로고침 뒤 이미 지난 알람은 바로 울림(최대 지각 1초 + 새로고침 시간).
- 탭이 여러 개면 각 탭이 울릴 수 있다(끄면 localStorage 로 다른 탭도 끔 — `storage` 이벤트).

### 4.5 울릴 때
- 소리: 소리 파일 없이 Web Audio 로 만든 "띠리리리"(짧은 높은 음 4번 반복, 0.6초 쉬고 반복). `src/chat/sound.ts`처럼.
- **소리 허용**: 브라우저는 사용자가 누르기 전 소리를 막으므로, 알람을 맞추는 버튼을 누르는 순간 AudioContext 를 만들고 resume 해 둔다. 새로고침 뒤 아직 아무것도 누르지 않았으면 소리가 막힐 수 있음 → 그때는 끄기 창에 "소리가 막혔어요. 아무 데나 한 번 눌러 주세요" 안내.
- **다른 탭에 가 있을 때 알아채기**: 끄기 전까지 탭 제목을 "⏰ 알람!"과 원래 제목으로 1초마다 번갈아 바꿈(권한 필요 없음). 브라우저 알림(Notification, 권한 묻기)은 쓰지 않음(제 판단: 권한 창이 공부 중 방해되고 범위가 커짐). 그래서 새로고침 뒤 아무것도 안 누르고 다른 탭에 가 있으면 소리 없이 탭 제목만 바뀔 수 있음 — 한계로 둠.
- 화면: 시계(창이 열려 있으면) 좌우로 흔들림 + **화면 가운데 끄기 창** "⏰ 알람 · 40분 지났어요 / 15:30 이에요 [끄기]" (창이 닫혀 있어도 뜸, 파스텔 민트 테두리).
- 끄기 누를 때까지 창은 남고, **소리는 1분 뒤 저절로 멈춤**. 끄기 창이 뜨면 1인칭 시점 잠금(포인터 잠금)을 풀어 바로 누를 수 있게.
- 소리 끔·방해금지와 무관하게 울림(3.3).

### 4.6 코드 나눔
- 순수 로직 `src/planner/clockLogic.ts`(React 무관, Node 검사): 스톱워치 경과 계산·시작/멈춤/초기화 상태 변화, 알람 울릴 시각 계산(몇 분 뒤·시각·지난 시각→다음 날), 남은 시간, 표시 글자(`MM:SS.cc`, `H:MM:SS`), localStorage 값 검사(깨진 값→초기 상태).
- 소리 `src/planner/alarmSound.ts`, 상태 훅 `useClock`, 화면 `ClockWindow.tsx`(본체·탭), `AlarmRinging.tsx`(가운데 끄기 창).

## 5. 그대로 두는 것
- 플래너·메모장·가방 버튼 위치, 집중 판정·공부 타이머, 채팅 소리·방해금지 동작.

## 6. 확인 방법
- 순수 로직 Node 검사(경과·멈춤·초기화, 몇 분 뒤·시각·지난 시각, 표시 글자, 깨진 저장값).
- `npm run lint`, `npm run build`.
- 화면(사용자 `npm run dev`): 모양(파스텔·질감), 스톱워치, 몇 분 뒤 알람(1분으로), 시각 알람, 다른 탭에 가 있을 때 제때 울림, 새로고침·화면 이동 뒤 이어짐, 시계 닫아도 울림, 소리 끔·방해금지 상태에서도 울림, 끄기.

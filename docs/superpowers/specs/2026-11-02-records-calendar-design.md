# 내 기록: 월 달력 + 과목별 비율 도넛 + 쉬는 날(OFF) (설계)

- 날짜: 2026-11-02
- 담당: 최원준
- 대상 브랜치: `develop` (서비스). 실험(`experiment`)과 무관
- 관련: 플래너 노트 넘기기 PR #394(과목 색을 같이 바꿈), 과목 관리 #369·#391(지운 과목)

## 1. 왜

기록 화면(`/records`, 로비·지점 위 창 `R`)의 월 단위는 지금 날짜별 세로 막대그래프다. 사용자가 다른 앱의 월 달력(칸마다 날짜·시간, 많이 한 날일수록 진한 색, 쉬는 날 OFF 표시, 옆에 과목별 비율 도넛)을 보여 주며 이렇게 보고 싶다고 했다.

원하는 것은 둘 다(사용자 답):
1. **한 달이 얼마나 빽빽하게 칠해졌는지 한눈에** 보는 맛
2. **날마다 몇 시간 했는지 숫자를 바로** 읽기

## 2. 목표 / 하지 않을 것 / 실패로 보는 것

**목표**
1. 월 단위의 막대그래프를 **달력**으로 바꾼다. 칸마다 날짜와 그날 집중 시간, 많이 한 날일수록 진한 초록.
2. 월·년 단위에 **과목별 비율 도넛**을 둔다.
3. 달력 칸을 눌러 **쉬는 날(OFF)** 을 켜고 끈다. 계정에 저장.

**하지 않을 것**
- 년 단위의 월별 막대그래프, 일 단위(과목별 가로 막대·공부 흐름 띠)는 그대로.
- 기록을 모으는 방식(`study_logs`, `recordsLogic` 합산, 자정 기준 날짜 경계) 변경.
- OFF 를 다른 사람에게 보여 주기, OFF 로 합계·연속 기록을 바꾸기.
- 새 라이브러리(차트 라이브러리 포함). 지금처럼 SVG·HTML 로 직접 그린다(`RecordCharts.tsx` 방식).

**실패로 보는 것**
- 숫자가 작거나 색과 겹쳐 시간이 안 읽힌다(특히 진한 칸).
- 좁은 창(로비 위 기록 창, 폰)에서 달력이 넘치거나 숫자가 잘린다.
- OFF 를 누르려다 다른 동작(창 닫힘 등)이 되거나, 눌렀는데 저장이 안 되는데 알 수 없다.
- 과목 색이 플래너 시간표의 같은 과목 색과 달라 헷갈린다.

## 3. 정해진 것 (사용자 결정)

### 3.1 월 달력
- 월 단위에서 **막대그래프를 달력으로 완전히 바꾼다**(전환 버튼 없음, 시안 그대로).
- 월요일 시작 7칸. 칸마다 **날짜 + 그날 집중 시간**(예: `5:20`, 0이면 비움).
- 칸 색: 많이 한 날일수록 **진한 초록**(서비스의 "공부 중 = 초록"). 아래에 색 단계 안내.
- 오늘은 테두리, 앞뒤 달 날짜는 흐리게.
- 지금 있는 ◀ ▶ 달 이동, 과목 칩, "이번 달 공부 시간" 합계, 표로 보기는 그대로. 과목을 고르면 달력도 그 과목 시간으로 칠한다.

### 3.2 쉬는 날(OFF)
- 월 달력에서 **날짜 칸을 누르면 OFF 켜기/끄기**. 지난날·앞날 모두.
- OFF 인 날은 칸에 작은 **"OFF" 딱지**. 공부 시간이 있으면 시간도 같이 보인다.
- **계정에 저장**(다른 기기에서도 보임).
- **다음 달까지 미리 찍을 수 있다** (사용자 결정): 월 단위에서만 ▶ 를 이번 달 다음 한 달까지 허용(지금은 미래 구간이면 막힘). 일·년 단위의 ▶ 막기는 그대로.
  - 미래 달 화면: 합계 `0분`, "공부 기록이 없어요" 글 대신 **빈 달력**(OFF 를 찍을 수 있게). 표로 보기·도넛은 숨김.
  - 이번 달에서도 공부 기록이 하나도 없으면 같은 규칙: 글 대신 빈 달력(OFF 를 찍어야 하므로). 월 단위만 해당.

### 3.3 과목별 비율 도넛
- 월 단위: 달력 아래에 그달 과목별 비율 도넛 + 옆에 과목 이름·%·시간.

## 4. 제가 정한 것 (사용자 확인 전 기본값)

### 4.1 달력
- 칸 색 단계: 0 / 2시간 미만 / 4시간 미만 / 6시간 미만 / 6시간 이상 (5단계). 기준값은 파일 위쪽 상수.
- 날짜 경계는 기록 화면 기존 그대로 **자정**(`byDayOfMonth`). (플래너의 새벽 5시 경계와 다르다 — 기록 화면 전체가 자정 기준이라 맞춤)
- 칸 안 글자는 진한 칸에서도 읽히게 흰 글자 + 칸 색은 어두운 배경(#20232a) 위의 초록 계열. 숫자 형식은 `H:MM`.
- 좁은 화면: 칸이 정사각형에 가깝게 폭을 나눠 쓰고, 칸 폭이 좁으면 날짜 글자를 줄인다(만드는 사람이 기준 정함). 가로 스크롤 금지.
- 앞날 칸은 공부 시간이 없으니 비어 있고, OFF 만 찍을 수 있다.
- 달력 그리기 순수 로직(그달 칸 배열: 앞뒤 달 채움, 요일 위치, 색 단계)은 `recordsLogic.ts`(또는 새 순수 파일)에 두고 Node 로 검사.

### 4.2 OFF
- OFF 는 **표시만** 한다. 합계·칸 색·도넛 계산에 영향 없음.
- **나만 본다**(프로필 공개 범위와 무관, 다른 사람 프로필 창에 안 나옴).
- 누르면 바로 바뀌어 보이고 저장, 실패하면 되돌리고 짧은 안내.
- 과목을 골라 본 상태에서도 OFF 는 같은 날에 그대로 보인다(날짜에 붙는 표시라서).
- 키보드로도 켜고 끌 수 있게 칸을 버튼으로(접근성).
- **게스트(익명 로그인)도 OFF 를 쓸 수 있다** (제 판단: 플래너 `planner_pages` 와 같은 취급, 개인 기록이라 남에게 영향 없음). 게스트 계정이 지워지면 같이 지워지도록 `user_id`는 `profiles` 를 `on delete cascade` 로 참조.
- DB: 새 표 `rest_days (user_id uuid default auth.uid() references profiles on delete cascade, day date, primary key (user_id, day))`, RLS 본인만 select·insert·delete. 새 마이그레이션 `supabase/migrations/0052_rest_days.sql`(develop 최신이 0051). 서비스 DB 에만 실행, 실험 DB 는 실행 안 함.
- 배포 순서: PR 머지 **전에** 서비스 Supabase 에 SQL 실행. 표가 없을 때(실행 전) 읽기 실패하면 OFF 없이 달력만 보이고 화면은 깨지지 않는다.

### 4.3 도넛
- **년 단위에도** 그해 비율로 같은 도넛을 둔다. 일 단위는 과목별 가로 막대가 이미 비율을 보여 줘서 그대로.
- **과목 칩으로 한 과목을 고르면 도넛은 숨긴다**(한 과목뿐이라 비율이 의미 없음).
- **과목 색 = 내 과목 목록 순서로 배정 (사용자 결정)**: 지금 플래너는 과목 번호(전체 공유 번호)를 8로 나눈 나머지로 색을 골라 내 과목끼리 같은 색이 자주 생김. 그래서 **내 과목 목록(`useSubjects`, 만든 순서, 정리한 과목 포함 — 순서가 바뀌지 않음)에서 몇 번째인지**로 8색 팔레트(지금 `plannerLogic` 의 PALETTE 그대로)를 고른다. 지운 과목(null)은 회색.
  - 이 함수 하나(예: `subjectLogic.subjectColorOf(list, id)`)를 **도넛과 플래너 시간표가 같이** 쓴다. 플래너 쪽(`PlannerSheet`/`PlannerWindow`)은 과목 목록을 읽어 넘기도록 조금 고친다. 기존 `plannerLogic.subjectColor(id)`는 이것으로 바꾼다.
  - 과목이 8개를 넘으면 9번째부터 색이 다시 돈다(어쩔 수 없음, 목록 이름으로 구분). 과목 목록을 읽기 전에는 회색.
- 순서는 많은 순, 비율은 반올림 정수 %. 아주 작은 조각(예: 2% 미만)은 도넛에는 그리되 % 글자는 옆 목록에만.
- 가운데에 그 기간 합계(`H:MM`).
- 도넛 조각 계산(각도·%)은 순수 함수로, Node 로 검사.

## 5. 그대로 두는 것
- 일·년 단위 화면(년은 도넛만 추가), 공부 흐름 띠, 꽃 피는 길, 표로 보기.
- `useStudyLogs`로 읽는 방식과 범위.

## 6. 확인 방법
- 순수 로직(달력 칸 배열, 색 단계, 도넛 조각·%) Node 검사.
- `npm run lint`, `npm run build`.
- 화면은 사용자가 `npm run dev`로: 숫자 읽힘, 진한 칸 대비, OFF 켜기·끄기·새로고침 유지, 과목 칩 선택 시 달력·도넛, 로비 위 기록 창과 폰 폭에서 넘침 없음, 0052 실행 전 화면이 깨지지 않음.

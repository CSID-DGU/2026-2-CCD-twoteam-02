## 1. 왜

광장(#315)은 늘 맑은 낮이다. 마인크래프트처럼 해와 달이 뜨고 지고 밤에는 별이 보이게 해서, "지금 이 시간에 함께 공부한다"는 느낌을 준다. 목적은 광장과 같이 서비스 분위기·몰입감이다.

## 2. 목표 · 하지 않는 것 · 실패로 치는 것

목표 (사용자 결정, 2026-10-30)
- 시간은 **현실 시각**을 따른다. 모두 같은 서울 하늘을 본다. 서버 없이 각자 컴퓨터 시계로 계산한다.
- 해는 **서울 실제 해**: 위도·계절에 따라 일출·일몰 시각과 낮 해 높이가 바뀐다.
- 달은 **실제 달 모양(위상)**: 초승달~보름달이 날짜대로 바뀌고, 달빛 세기도 위상을 따른다.
- 밤은 **분위기만 밤**: 하늘은 진한 남색에 별, 땅·길·건물·캐릭터는 또렷이 보여 걷기에 불편이 없다. 가로등·건물 창문이 따뜻하게 빛난다.
- 하늘은 drei `Sky`(낮·노을) 위에 남색 "밤 덮개"를 해가 질수록 진하게 씌우는 방식이다. (사용자 결정: 1번 방식)
- 확인용으로 시각을 고정하거나 빨리 돌릴 수 있다.

하지 않는 것
- 지점 실내 변경(창밖 풍경, 실내 조명). 실내는 지금 그대로다.
- 구름·비(#317).
- 실제 달 궤도 계산. 달 위치는 근사다(4절).
- 서버 시각 맞추기. 컴퓨터 시계가 틀리면 그 사람 하늘도 틀린다.
- 별자리 정확성. 별은 무작위지만 늘 같은 자리다.

실패로 치는 것
- 밤에 길·건물·캐릭터를 알아보기 어려워 걷기가 불편한 것.
- 일반 노트북에서 낮이든 밤이든 30FPS 아래로 떨어지는 것.
- 미니맵에 하늘이 끼어 월드 바깥이 하늘색·남색으로 보이는 것.
- 시간이 빠르게 흐를 때(`?speed`) 해·달·빛이 끊기며 튀는 것.

## 3. 시각

- 기준은 컴퓨터 시계의 절대 시각(UTC)이다. 위치는 서울(위도 37.5665°N, 경도 126.9780°E)로 고정한다. 그래서 다른 시간대의 컴퓨터로 접속해도 모두 같은 서울 하늘을 본다.
- 주소로 바꿀 수 있다(진행자·개발 확인용):
  - `?time=HH:MM` 또는 `HH:MM:SS`: 오늘 그 서울 시각에서 시작한다(`?speed`가 없으면 그 시각에 멈춤).
  - `?speed=N`: N배 빠르게 흐른다(예: 600 이면 1분에 10시간). `?time`과 같이 쓰면 그 시각부터 흐른다.
  - 모양이 틀리면(예: `25:99`, `abc`, 0 이하) 그 값만 무시하고 현실 시각을 쓴다.

## 4. 계산 (`src/world/skyLogic.ts`, 순수 함수)

**해** — `sunPosition(date) → { altitude, azimuth }` (라디안)
- NOAA 방식 근사식: 율리우스 세기 → 태양 평균 경도·평균 근점 이각 → 황경 → 적위·균시차 → 시간각 → 고도·방위. 오차 1° 안쪽.
- 방위는 북쪽 0, 동쪽 +π/2 (3D 로 옮길 때 6절의 변환을 쓴다).

**달**
- `moonPhase(date) → { phase, lit }`: 기준 삭 2000-01-06 18:14 UTC 에서 지난 날 수를 삭망월 29.530589 일로 나눈 나머지(0~1). 0 그믐, 0.25 상현, 0.5 보름, 0.75 하현. `lit` = 밝은 부분 비율 = (1 − cos 2π·phase) / 2.
- `moonPosition(date) → { altitude, azimuth }`: 해가 지나는 길을 위상만큼 늦게 따른다고 본다. 달의 시간각 = 해의 시간각 − 2π·phase, 적위 = 해의 적위 × cos 2π·phase (삭이면 해와 같고 보름이면 반대라 겨울 보름달이 높이 뜬다). 보름이면 해 반대편, 초승달이면 해 질 녘 서쪽 하늘. 실제 궤도와 몇 도 다르지만 모양과 뜨는 때가 맞다.

**화면 값** — `skyState(date) → SkyState`
- `night` 0~1: 해 고도 −2°에서 0, −12°에서 1, 사이는 부드럽게(smoothstep).
- 햇빛(방향광): 고도 > 0 이면 해 쪽에서, 세기 0.9 × (낮 비율), 색은 고도 15° 이상 흰색 → 0°에 가까울수록 주황(`#ffb070`). 밤에는 달 쪽에서, 세기 0.25 × `lit` × `night`, 색 `#9fb8ff`. 달이 지평선 아래면 0.
- 주변광: 세기 1.0(낮) → 0.45(밤), 색 흰색 → `#8fa3d6`. "분위기만 밤"이라 바닥값을 높게 둔다.
- 가로등·창문 빛남 = `night`.
- 별 투명도 = (`night` − 0.6) / 0.4 를 0~1 로 자른 값.
- 기준값(−2°, −12°, 0.45, 0.6 등)은 파일 위쪽 이름 붙인 상수로 둔다.

**시각 읽기** — `parseClock(search, now) → { start: number; speed: number; base: number }`, `worldTime(clock, nowMs) → Date`
- 3절 규칙. `worldTime = start + (nowMs − base) × speed`.

## 5. 그리기 (`src/world/WorldSky.tsx`)

- 매 프레임 `useFrame`에서 `skyState`를 계산해 ref 에 담고 three.js 값(위치·세기·색·투명도)을 직접 바꾼다. React 다시 그리기 없음. `?speed`가 커도 부드럽게 움직인다.
- **낮 하늘**: drei `Sky` (distance 450). 매 프레임 해 방향만 바꾼다.
- **밤 덮개**: 반지름 400 의 구 안쪽 면, 머리 위 `#0b1630` → 지평선 `#24365f` 정점 색 그라데이션, 투명도 = `night`, 깊이 쓰기 끔.
- **별**: drei `Stars`는 바깥에서 투명도를 받지 않아 직접 만든다. 반지름 350 구 위 무작위 점 약 2,500개(`THREE.Points`, 고정 씨앗값이라 늘 같은 자리, 지평선 아래 제외), 투명도는 4절 값.
- **달**: 반지름 330 거리, 늘 카메라를 보는 판(drei `Billboard`). 위상에 맞춰 밝은 부분·그림자 경계를 캔버스에 그린 그림. 위상이 1% 바뀔 때만 다시 그린다. 조명 영향 없음(`toneMapped` 끔).
- **빛**: 방향광 1개(해 또는 달 쪽, 4절 값), 주변광 1개, 광장 네 모서리 가로등 자리의 따뜻한 점광원 4개(`#ffd28a`, 반경 12m, 세기 ∝ `night`, `night` 0 이면 `visible=false`).
- **가로등·창문**: `WorldDecor`에 `setNightGlow(night)`를 둔다. 공용 재질 두 개의 빛남을 바꾼다: 가로등 등 0.3 → 1.6, 창문 0 → 0.9(색 `#ffcf7a`).
- **미니맵**: 하늘 부품(Sky·밤 덮개·별·달)은 레이어 2 에 둔다. 화면 카메라는 레이어 2 를 켜고, 미니맵 카메라는 켜지 않는다. 미니맵의 월드 바깥은 지금처럼 어두운 색이다.
- `WorldScene`의 고정 배경색·조명 두 줄을 `<WorldSky />`로 바꾼다. 위에서 보기(V)에서도 밤이면 어둡고 가로등이 켜진다.

## 6. 하늘 방향 → 3D

해·달의 (고도 a, 방위 z, 북 0·동 +π/2)을 3D 방향으로: `x = cos a · sin z`, `y = sin a`, `z3 = −cos a · cos z`. (3D 는 −Z 가 북쪽)

## 8. 성능

- 늘어나는 그리기: 하늘 1, 밤 덮개 1, 별 1, 달 1, 점광원 4.
- 점광원은 바닥·건물 재질 계산을 늘리므로 4개로 제한하고 낮에는 끈다.
- 매 프레임 계산은 삼각함수 수십 번. 달 그림은 위상 1% 마다만 다시 그린다.
- FPS 표시로 `?time=12:00`, `?time=22:00` 을 각각 재서 30 이상.

## 9. 확인 방법

`skyLogic` (Node, 스크래치패드 검사 스크립트)
- 일출·일몰(해 고도 −0.833°, 달력 기준): 서울 하지 05:11·19:57, 동지 07:43·17:17 (± 3분), 2026-10-30 06:55·17:36 (± 5분)
- 하지(2026-06-21) 정오 무렵 최고 고도 약 76° ± 1°, 동지(2026-12-21) 약 29° ± 1°

- 서울 정오 `night` 0, 자정 `night` 1
- `parseClock`: `?time=21:30` → 오늘 서울 21:30, 속도 0(멈춤) / `?speed=600` → 600 / `?time=25:99`·`?speed=-1`·`?speed=abc` → 무시

## 16. 집중 상태 판정, 전자기기 감지, 실시간 동기화의 학술적 근거 조사

- 라벨: `P1 이번 학기` `조사` `공통`
- 코딩이 아니라 논문을 읽고 근거를 찾는 작업

**지금까지 확인한 것**
- 프로젝트에 올린 논문 2편(Lee 외 2021, Hoyt 외 2003)은 자리 이탈과 전자기기 기준의 근거가 된다.
- 졸음 기준과 기준값(몇 초, 임계값)의 근거는 두 논문에 없다.
- Hoyt 논문은 "아바타 뒤에 실제 사람이 있다고 믿을 때만 영향이 생긴다"는 결과라서, 실시간 동기화가 필요한 이유의 근거가 된다.

**할 일**
- [ ] 집중 상태 판정: 졸음 판정 지표에 대한 문헌 찾기
- [ ] 전자기기 감지: 스마트폰과 주의력에 대한 문헌 찾기
- [ ] 실시간 동기화: 다른 사람의 움직임이 얼마나 늦게 보여도 "함께 있다"는 느낌이 유지되는지에 대한 문헌 찾기
- [ ] 기준값의 근거 찾기, 없으면 직접 측정으로 정한다는 계획 세우기
- [ ] 기준별 근거를 한 문서로 정리

**완료 기준**
자리 이탈, 졸음, 전자기기, 실시간 동기화 각각에 대해 "왜 이렇게 했는가"를 문헌으로 답할 수 있다.

- 라벨: `P2 후순위` `기능` `화면` `백엔드`

- 확인할 것: 주기 중간에 들어온 사람의 처리, 휴식 시간의 판정과 타이머

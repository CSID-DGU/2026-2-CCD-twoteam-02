# 집중 판정 기준값과 근거

집중 판정(`src/focus/focusLogic.ts`)에 쓰는 기준값을 **왜 그 값으로 정했는지** 기록하는 문서다.
연구·업계 기준에서 근거를 찾아 값을 정하고, 코드 상수는 이 문서에 맞춘다.

- **원칙: 확실한 경우만 잡고, 애매하면 공부로 인정한다.** 공부 습관은 사람마다 달라서, 애매한 경우까지 나누려 하면 오판이 늘어난다.
  - 그래서 "공부 중인지"를 판정하지 않고, **누구에게나 분명한 "공부가 아닌" 상황**(자리에 없음, 다른 화면, 정면에서 오래 눈 감음, 카메라가 돌아감)만 노란불로 잡는다. 턱 괴기·기대기·숙이기처럼 사람마다 다른 자세는 모두 초록이다.
  - 실패는 "공부를 안 했는데 초록"(놓침) 쪽으로 두고, "공부했는데 노랑"(억울한 오판)을 줄인다.

### 기준값은 세 층으로 나눈다 (2026-10-15)

| 층 | 무엇 | 예 | 근거를 세우는 방법 |
|---|---|---|---|
| 1. 정책 기준 | 몇 초 지나면 노랑인지 같은 **규칙** | 자리 이탈 60초, 졸음 21초, 카메라 안내 10초 | 외부 기준 인용 + 위 원칙. 사람마다 다를 이유가 없는 값이라 모두에게 같게 쓴다. |
| 2. 자동 보정 | 몸·자리마다 다른 **물리적 값** | 눈 크기(눈 감음), 정면 고개 각도(숙임), 화면 속 어깨 위치(가이드라인) | 팀이 고정값을 정하지 않는다. **공부 시작 때 그 사람의 평소 값을 재서 기준으로 삼고**, 거기서 얼마나 달라졌는지로 판단한다. 남는 여유값(변화의 크기)은 사람마다 덜 다르므로 공통으로 쓴다. |
| 3. 평가 | 1·2층이 실제로 맞는지 | 각본 시험, 오판 신고(#121) | 기준을 만드는 단계가 아니라 **검증**하는 단계. 여러 사람으로 오판률을 재서 그대로 보고한다. |

- 팀원 몇 명의 측정으로 2층 값을 고정값으로 정하면, 사용자마다 다른 몸·자리를 대표할 수 없다. 이런 값은 자동 보정으로 바꾼다.
- 사용자가 기준을 직접 고르는 설정은 두지 않는다(기준을 느슨하게 해 공부 시간을 부풀릴 수 있고, 실험 조건이 참가자마다 달라짐). 사용자가 고르는 것은 "학습기기 사용함"처럼 공부 방식에 대한 선택만 둔다.
- 출처 표시: **[원문]** 원문 직접 확인 / **[공식]** 기업·기관 공식 문서 / **[2차]** 요약·2차 자료 / **[측정]** 팀이 직접 잰 값
- 담당: 최원준. 마지막 수정: 2026-10-15

## 결정 요약

| 항목 | 기준 | 코드 상수 |
|---|---|---|
| 자리 이탈 | 얼굴이 **60초** 넘게 안 보이면 | `AWAY_SECONDS` |
| 졸음 | 정면을 보며 눈을 **21초** 넘게 계속 감으면 | `DROWSY_SECONDS` |
| 고개 숙임 | 고개를 숙이면(위아래 각도 **0°** 초과) 졸음 판정을 하지 않음 → 공부로 인정 | `HEAD_DOWN_DEGREES` |
| 눈 감음 | 감긴 정도 **40%** 넘으면 감음, **30%** 아래로 내려가야 다시 뜸 | `EYE_CLOSED_SCORE`, `EYE_OPEN_SCORE` |
| 잠깐 안 보임 | 기준 시간 전까지는 공부 시간으로 인정 | `focusLogic.ts` 로직 |
| 카메라 화면 안 | 코·양 어깨 x가 0.02~0.98, 코 y가 0.02~1, 어깨 y가 **1.02** 이하 (visibility는 안 씀). **임시, 자동 보정으로 바꿀 값** | `EDGE_MARGIN`, `SHOULDER_MAX_Y` |
| 카메라 문제 안내 | 구도 잘림, 또는 사람이 없고 배경이 바뀐 상태가 **10초** 이어지면 안내. 사람이 없고 배경이 그대로면 자리 이탈로 보고 안내 안 함 | `GUIDE_ALERT_SECONDS`, `BG_SAME_SCORE` |

사람마다 다른 부분은 나중에 사용자 조정 기능으로 보완한다. 실험 기간에는 모든 참가자에게 같은 기준을 쓴다.

## 1. 자리 이탈 — 60초

### 근거
- **공부 분야에는 공개된 기준이 없다.** 공부·캠스터디 앱과 웹캠 집중도 연구에서 "얼굴이 몇 초 안 보이면 이탈"이라는 기준을 공개한 곳은 찾지 못했다.
- 그래서 같은 질문("사람이 컴퓨터 앞에 있나")을 카메라·센서로 푸는 분야의 기준을 가져온다.

| 출처 | 기준 | |
|---|---|---|
| Dell Walk Away Lock | **60초** 넘게 떠나 있으면 잠금 | [공식] |
| Moodle 시험 감독 플러그인 | 얼굴이 안 보여도 **10초** 유예 | [2차] |

- 이 분야들은 목적(보안·시험 감독)이 공부와 다르다. 그래서 범위(10~60초) 안에서 공부 상황에 맞는 쪽을 고른다.

### 60초를 고른 이유
- 공부 중에는 옆에 둔 책을 보거나 물을 마시느라 고개를 돌리는 일이 흔하다. 얼굴 인식은 고개를 좌우로 약 45도 넘게 돌리면 얼굴을 놓친다(Microsoft도 "화면을 보고 있다"의 기준을 ±45도로 권장 [공식]).
- 짧게 잡으면 자리에 있는데도 이탈로 잘못 판정된다. 그래서 Dell처럼 **확실히 떠났을 때만** 이탈로 본다.

## 2. 졸음 — 정면에서 21초 계속 감음

### 운전 기준을 그대로 쓰지 않는 이유
- Euro NCAP 운전자 모니터링 기준은 눈을 **1~2초** 감으면 미세수면, **3초** 감으면 잠든 것으로 본다. [원문]
- 운전은 1초만 졸아도 사고가 나서 짧게 잡는다. 공부는 졸아도 위험하지 않고, 눈을 감고 쉬거나 생각하는 경우가 흔하다. 짧은 기준을 쓰면 공부 시간을 잘못 끊는 경우가 많아진다.
- 그래서 "잠깐 졸았다"보다 **"잠들었다"**에 가까운 기준을 쓴다.

### 21초의 근거
- **OSLER 검사**(깨어 있기 능력 검사)는 **21초** 동안 반응이 없으면 잠든 것으로 판정한다. 뇌파 측정과의 일치도는 ICC 0.91이다. [2차]
- 미세수면(짧게 조는 것)은 길어야 약 **15초**다. [2차] 21초는 이보다 길어서, 잠깐 눈을 감고 쉬는 것은 졸음으로 잡지 않는다.

### 쓰지 않기로 한 것: 눈 감은 비율(PERCLOS)
- PERCLOS(일정 시간 중 눈을 감고 있던 비율)는 운전 졸음 연구에서 가장 많이 검증된 지표다(Dinges 외 1998, 미국 NHTSA). [2차] 꾸벅꾸벅 조는 경우를 잡으려고 "1분 중 12%"를 함께 쓰려 했다.
- 하지만 12%는 1분 중 7.2초라서, 정면에서 **8초만 눈을 감고 쉬어도 졸음**이 된다(로직 시험으로 확인). 21초 기준과 마찬가지로 운전용 기준이라 공부에는 맞지 않아 뺐다.

### 확인 방법
실제로 졸게 만들 수는 없으므로, Euro NCAP 시험처럼 **정해진 시간만큼 눈을 감는 연기**로 판정이 제때 바뀌는지 확인한다.

## 3. 눈 감음 점수와 고개 숙임

### 눈 감김 점수는 실제로 감긴 비율이 아니다
- MediaPipe 눈 감김 점수(eyeBlink)는 0~1 값이지만, 아바타 얼굴을 움직이는 오락용 모델이 아티스트가 만든 "눈 감은 표정"에 얼마나 가까운지를 낸 값이다. 눈 감김 정확도는 공개하지 않았다. [원문 — MediaPipe 모델 카드]
- 그래서 문헌의 기준값을 그대로 쓸 수 없고, 실제 값을 직접 쟀다.

### 측정 (2026-10-13, 노트북 내장 카메라, 안경 착용, 1명) [측정]

| 행동 | 감긴 정도 | 고개 위아래 |
|---|---|---|
| 정면, 눈 뜸 | 11~19% | −4~−7° |
| 정면, 반쯤 감음 | 31% | 0° |
| 정면, 완전히 감음 | 50~52% | −3~−6° |
| 고개 숙여 필기 (눈 뜸) | 42~54% | +9~+12° |
| 고개 숙인 채 눈 감음 | 52% | +13° |

### 결정
- **눈 감음 40% / 다시 뜸 30%**: 정면에서 뜬 값(최대 19%)과 감은 값(최소 50%) 사이. 두 값을 나눠 둔 것은 경계에서 상태가 깜빡이지 않게 하기 위해서다.
- **고개를 숙이면 졸음 판정을 하지 않는다 (공부로 인정).**
  - 고개를 숙여 필기하면 눈을 감은 것과 점수가 같게 나온다(42~54%). 숙인 채 조는 것(52%)과도 감긴 정도·고개 각도로는 구분할 수 없었다.
  - "시선이 아래로 간 정도"(eyeLookDown) 점수로 나눠 보려 했지만, 눈을 감아도 이 값이 같이 올라가서(47~52%) 구분이 안 됐다. [측정]
  - 운전자 모니터링에서도 고개를 숙이면 눈꺼풀 상태를 확인하기 어렵다는 것이 알려진 문제다. [2차 — 자동차 업체 특허]
  - 숙여서 하는 공부는 필기·읽기·암기 등 다양해서 팔 움직임 같은 다른 신호로도 나눌 수 없다고 봤다.
- **고개 숙임 기준 0°**: 정면(−4~−7°)과 숙임(+9~+13°) 사이.
- 착석 때 사람별로 보정하는 방법도 검토했지만, 단순하게 가기 위해 고정값을 쓴다.

### 한계
- **고개를 숙인 채 조는 것은 공부로 들어간다.** 책상에 엎드려 자서 얼굴이 사라지면 60초 뒤 자리 이탈로 잡힌다.
- 측정은 1명·1회라서, 실험 기간에 오판이 많으면 값을 다시 조정한다.
- 나중에 개선할 것: 졸 때는 고개가 갑자기 툭 떨어진다(꾸벅임). 공부하며 숙이는 움직임과 구분할 수 있을지 검토한다.

## 4. 잠깐 안 보인 시간 — 공부 시간으로 인정 (Issue #79)

- **기준 시간 전까지는 공부 시간으로 인정한다.**
  - 얼굴이 안 보여도 60초 전에 돌아오면 그 시간은 공부 시간이다. 60초가 되면 자리 이탈이 되고, 안 보인 60초는 뺀다.
  - 눈 감음도 같다. 21초 전에 뜨면 공부 시간이고, 21초가 되면 졸음이 되며 감은 21초는 뺀다.
  - 이유: 1·2번 기준이 "이보다 짧으면 이탈·졸음이 아니다"라는 값이다. 이탈·졸음이 아닌 시간은 공부 중으로 보는 것이 일관된다.
- **화면 표시**: 안 보이는 동안에도 타이머는 계속 올라가고, **내 화면에만** "얼굴을 찾는 중" 같은 노란 표시를 띄운다.
  - 잠깐 안 보이는 흔한 경우에 숫자가 갑자기 뛰지 않는다(Issue #79에서 지적한 문제).
  - 다른 참여자에게 보이는 내 표시등은 초록 그대로 둔다. 그 시간도 공부 시간으로 인정되고, 고개만 돌려도 표시등이 바뀌면 다른 사람에게 혼란을 준다.
  - 저장되는 공부 기록에는 확정된 시간만 들어간다. 기준을 넘겨 빠지는 시간이 기록에 들어가는 일은 없다.

## 5. 카메라 가이드라인 — 화면 안 기준과 배경 비교

- **용도: 카메라 구도 확인.** 정상일 때는 아무 알림이 없고, 카메라가 이상할 때만 "(가이드라인) 카메라에 머리와 어깨가 보이도록 맞춰 주세요" 안내를 띄운다. 공부 타이머는 멈추지 않는다(타이머에 쓸지는 각본 시험으로 정함).
- 설계: `docs/superpowers/specs/2026-10-15-camera-guide-redesign-design.md`

### 화면 안/밖은 좌표로만 본다
- Pose는 화면 밖 관절도 위치를 추정하고, 그때도 visibility(보이는 정도)를 0.98~1.00으로 낸다 **[측정 2026-10-13]**. 그래서 visibility로는 화면 안/밖을 가를 수 없다(Issue #80).
- 화면 밖 관절은 좌표가 0~1을 벗어난다(측정: 한쪽 어깨를 빼면 x −0.35까지). 좌표만 보면 #80 상황을 82% 잡는다 **[측정]**.

### 어깨 아래쪽 한계 1.02 (임시 — 1명 측정, 자동 보정으로 바꿀 값)
- 정상 자세에서도 어깨는 화면 아래쪽(y 0.86~0.90)이라 여유가 거의 없다.
- 의자에 기대 누우면 어깨 y가 최대 **1.011**, 카메라를 위로 젖히면 대부분 **1.03 이상**(중간값 1.095)이다 **[측정]**. 그 사이인 1.02로 정했다.
  - 1.0이면 기대 눕기가 4.5초 연속 "밖"이 되어, 오래 기대 읽으면 정상 공부 중에 안내가 뜬다.
  - 1.02여도 카메라 위로는 17.5초 연속 잡힌다.
- 여유가 좁다(0.01~0.02). **1명·1자리 측정이라 근거로 약하다.** 2층(자동 보정) 값이므로, 착석 때 잡은 기준 자세에서 얼마나 벗어났는지로 판단하도록 바꾼다.

### 자리 이탈과 카메라 돌아감은 배경으로 가른다
- 자리를 떠나면 사람만 사라지고 배경은 그대로, 카메라가 돌아가면 배경 전체가 바뀐다.
- 1초마다 영상을 8×6칸 평균 밝기 숫자로만 읽어(그림은 남기지 않음) 기준 배경과 상관계수(무늬가 닮은 정도)로 비교한다. 방 전체 밝기 변화는 상관계수에 영향이 작다.
- 사람이 차지한 칸(머리·몸통)은 비교에서 뺀다. 평소 거리에서 18~35칸이 남는다 **[측정]**.
- 기준 배경은 Pose와 얼굴 인식이 **둘 다** 사람을 볼 때만 바꾼다. 카메라를 벽으로 돌렸을 때 Pose가 1.3초 동안 벽을 사람으로 착각한 일이 있었다 **[측정]**.
- 배경 같음 기준 0.8 (임시 — 처음 고른 값이 1명 측정값 사이에 있음을 확인한 것뿐): 자리를 떠났을 때 0.96~0.97, 뒤로 사람이 지나갈 때 1.00, 카메라를 벽으로 돌렸을 때 −0.17~0.75 **[측정]** → 그 사이.
- 무늬 없음 기준 8(밝기 표준편차): 측정한 배경은 모두 32~53이라 이 기준이 쓰인 적이 없다. **검증 안 됨.** 흰 벽처럼 무늬가 없으면 배경 비교 대신 최근 10초 안 키보드·마우스 입력으로 사람이 있는지 본다.

### 측정 결과 (2026-10-15, 최원준 1명, 책상·의자, `/tracking` 측정 기록) — 동작 확인용, 기준 확정 근거로는 부족

| 상황 | 기대 | 결과 (가장 길게 이어진 문제 시간) |
|---|---|---|
| 정상 착석, 기지개, 카메라에 바짝 붙음, 카메라 조금 돌림 | 안내 없음 | 0~0.3초 |
| 숙여서 필기 (총 55초) | 안내 없음 | 0.1초 |
| 의자에 기대 눕기 (총 43초) | 안내 없음 | 1.02 기준 0초 |
| 한쪽 어깨 화면 밖 (#80) | 안내 | 8.3초 중 6.8초 |
| 카메라 왼쪽·오른쪽 크게, 위로 | 안내 | 18초 / 6.7초 / 17.5초 연속 |
| 카메라를 벽으로 돌림 | 안내 | 8.7초 연속 (배경 바뀜) |
| 자리 떠나기 | 안내 없음 | 일어나는 4초만 구도 잘림, 나간 뒤 배경 같음 |
| 스탠드 켜고 끄기, 뒤로 사람 지나감 | 안내 없음 | 1.5초, 2.8초 |

- 한계: 1명·1자리 측정이다. 누워서 노트북으로 찍는 자세(어깨 y 1.18)는 책상 공부가 아니라 측정에서 뺐고, 이 자세에서는 안내가 뜬다.

# 발표자료 제작 가이드 · 다음 PPT용 프롬프트

2026-11-11

## 이번에 만든 방법

이번 중간발표 자료(21쪽, 1920×1080)는 "내용과 대본을 먼저 확정하고, 캔바에서 Claude에게 한 쪽씩 고치게 하는" 방식으로 만들었습니다.

1. **내용 정리:** 제안서와 깃허브 기록(커밋·PR 수, 일정)을 바탕으로 쪽별 메시지를 정했습니다.
2. **발표자 노트에 대본:** 각 쪽 노트에 `[발표자 · 시간]` 형식으로 대본을 쓰고, 고칠 점은 노트에 메모로 남겼습니다. (예: "여기에 회의 사진 넣기")
3. **초안 덱:** pptx 초안을 만들어 캔바로 가져왔습니다.
4. **캔바에서 쪽별 수정:** Claude에 캔바를 연결해 "N쪽 사진 맞춰", "N쪽 표 다시"처럼 한 쪽씩 지시했습니다. Claude가 고치고 바로 저장합니다.
5. **사진은 직접 넣기:** 게임 화면 캡처나 슬랙 캡처를 캔바에서 직접 넣고, 크기와 자르기는 Claude에게 맞추게 했습니다.
6. **표지·목차·마지막 장 따로 다듬기:** 배경 사진 위 그라데이션, 목차를 각 쪽 소제목과 맞추기 등 별도로 손봤습니다.
7. **대본 다듬기:** 화면 흐름(기존 → 지금 → 이유)에 맞춰 노트 대본을 정리했습니다.

최종 목차 구성은 배경(3–6) · 기능(7–12) · 실험(13) · 데이터베이스(14–15) · 운영(16–17) · 시연(18) · 남은 일정(19), 그리고 참고문헌(20, Q&A용)과 마무리(21)입니다.

## 피드백으로 정해진 규칙

이번에 여러 번 다시 하게 만든 원인들입니다. 다음에는 처음부터 이 규칙을 주면 수정 횟수가 크게 줄어듭니다.

**소통**

- 항상 한국어 존댓말로 답한다.
- 수정은 물어보지 말고 바로 저장한다. 보고는 무엇을 바꿨는지 짧게.
- 발표자 노트(대본)는 절대 손대지 않는다.
- 한 번 말한 것을 두 번 말하게 하지 않는다. 비슷한 문제는 다른 쪽까지 알아서 찾아 고친다.

**문구**

- 오글거리는 슬로건, 주저리주저리 긴 문장 금지. 담백하게.
- 마지막 장은 "감사합니다" 정도만.
- "건너편 · 2팀 두뜀 · 중간발표" 같은 하단 문구를 넣지 않는다.
- 표는 내용에 맞게 구조를 생각해서 짠다. 두 열에 같은 말이 반복되면 항목 열을 따로 둔다.

**사진**

- 캡처 사진의 위쪽을 자르지 않는다. 보낸 사람·프로필이 보여야 한다. 자를 때는 아래나 오른쪽을.
- 가짜 둥근 모서리(사진 위에 모서리 가림판 얹기) 금지.
- 사진을 넣으면 "[사진] …" 자리표시 글상자는 지운다.
- 사진 주변에 필요 없는 테두리·흰 상자를 두지 않는다.

**모양**

- 둥글지도 뾰족하지도 않은 찌그러진 상자 금지. 모서리는 네 귀퉁이 같게.
- 카드·검은 원·베이지 상자를 나열한 전형적인 템플릿 느낌("밤티")을 피한다.
- AI가 만든 티가 나는 장식(장식용 점, 과한 강조색)을 빼고, 덱에 이미 있는 스타일을 따른다. (예: 목차는 3쪽과 같은 왼쪽 남색 판 + 큰 베이지 번호)
- 사진 위 글씨는 계단이 보이지 않는 자연스러운 그라데이션 위에 올린다.

## 캔바 작업 팁

Claude가 캔바를 고칠 때 막혔던 곳과 해결법입니다. 다음에 같은 상황이 오면 이 방법을 바로 쓰라고 하면 됩니다.

| 상황 | 해결법 |
| --- | --- |
| 사진을 틀에 맞추기 | 크기를 줄이면 오른쪽·아래가 잘린다. 위쪽은 살리고 아래를 자른다. 왼쪽·위쪽을 자를 때만 뒤집기 → 크기 조절 → 되돌리기 |
| 찌그러진 둥근 상자 | 상자 크기와 같은 크기의 둥근 사각형 도형으로 교체한다 (모서리 14~18) |
| 새 글상자가 다른 글꼴로 들어감 | Claude는 글꼴을 바꿀 수 없다. 기존 글상자를 재활용하거나, 캔바에서 직접 복사해서 넣는다 |
| 사진 위 글씨가 안 보임 | 아주 연한 반투명 판을 10~12px씩 겹쳐 그라데이션을 만든다 (판 12장 정도로는 계단이 보인다) |
| 글자 그림자 | Claude가 못 넣는다. 캔바에서 글씨 선택 → 효과 → 그림자 |
| 그라데이션 판이 자꾸 클릭됨 | 글씨를 직접 골라 선택하거나, 판들을 잠근다 |
| 쪽번호가 바뀜 | 표지를 새로 넣거나 지우면 쪽이 밀린다. 요청할 때 "지금 기준 N쪽"이라고 말한다 |

배경 사진은 캔바에 직접 올리는 것이 가장 빠릅니다. Claude 작업 환경에서는 캔바로 파일 업로드가 막혀 있었습니다.

## 다음에 Claude에게 줄 프롬프트

아래 글을 통째로 복사해 첫 메시지로 보내면 됩니다. `[ ]` 부분만 채우세요. 가장 효과가 큰 건 중간발표 캔바 디자인을 복사해서 시작하는 것입니다. 글꼴·색·헤더 위치가 그대로 따라옵니다.

```text
[최종발표] 발표자료를 캔바로 만들려고 해. 항상 한국어 존댓말로 답해줘.

## 상황
- 팀: 2팀 두뜀 / 서비스: 건너편(Opposeat), 행동반영 아바타 온라인 스터디카페
- 발표: [날짜], [발표 시간]분, 발표자 [이름들]
- 자료: 프로젝트 문서(제안서), 깃허브 https://github.com/CSID-DGU/2026-2-CCD-twoteam-02, [추가 자료]
- 기준 디자인: 캔바 중간발표 덱(ID DAHaHm1o3mU)을 복사해서 시작. 글꼴·색·헤더 위치는 그대로 쓴다.
- 이번 발표에서 꼭 보여줄 것: [실험 결과, 사용자 테스트 결과 등]

## 진행 방식
1. 먼저 목차와 쪽별 핵심 한 줄을 표로 보여줘. 내가 OK하면 만든다.
2. 그 다음부터 수정은 물어보지 말고 바로 저장(commit)하고, 무엇을 바꿨는지 짧게만 말해줘.
3. 발표자 노트는 절대 고치지 마. 대본은 내가 쓴다. 노트에 있는 메모("여기에 … 넣기")는 참고만 하고 할 일로 알려줘.
4. 한 쪽에서 지적한 문제는 다른 쪽에도 있는지 알아서 찾아서 같이 고쳐줘.
5. 저장 전에 썸네일로 직접 확인해줘.

## 레이아웃 (1920×1080)

- 제목 위 98(도형)/108(글상자), 왼쪽 86, 56px 굵게
- 본문 196~996, 오른쪽 끝 1834
- 쪽번호 위 1016, 왼쪽 1700
- 배경 #faf6ee / 어두운 장 #1d1f25, 글자 #1d1f25, 보조 회색 #666464
- 강조색은 초록·노랑·빨강(집중 상태 신호등)만 쓴다.
- 상자는 모서리가 균일하게 둥글게(14~18). 찌그러진 상자 금지.
- 내용이 넘치면 상자를 줄여서 맞춘다.

## 하지 말 것
- 오글거리는 슬로건, 긴 감성 문장. 마지막 장은 "감사합니다"만.
- "건너편 · 2팀 두뜀 · …" 같은 하단 문구
- 카드+검은 원 같은 템플릿 느낌, AI 티 나는 장식. 덱에 이미 있는 스타일을 따라라.
- 같은 말이 두 열에 반복되는 표. 표는 구조를 생각해서 짜라.
- 새 글상자 추가(글꼴이 바뀜). 기존 글상자를 재활용하고, 부족하면 나한테 복사해 달라고 해.

## 사진
- 사진은 내가 캔바에 넣는다. 너는 크기·자르기·배치만 맞춰.
- 캡처는 위쪽을 절대 자르지 마(보낸 사람·프로필이 보여야 함). 아래나 오른쪽을 자른다.
- 가짜 둥근 모서리(가림판) 금지. 필요 없는 테두리·흰 상자도 금지.
- 사진을 넣으면 "[사진] …" 자리표시는 지운다.
- 사진 위 글씨는 연한 반투명 판을 10~12px씩 겹친 자연스러운 그라데이션 위에 올리고, 글씨는 맨 앞으로.
```

제작 중에는 짧게 지시해도 됩니다. 이번에 잘 통한 말투입니다.

- "N쪽 사진 맞춰" — 크기·자르기·자리표시 삭제까지 한 번에
- "N쪽 표 다시. [무엇이 이상한지]" — 이유를 한 줄 붙이면 한 번에 맞는다
- "N쪽은 3쪽과 같은 스타일로" — 기준 쪽을 짚어주면 "밤티" 디자인을 피한다
- "N쪽 대본 정리. 화면 흐름에 맞춰" + 초안 붙여넣기

## 완성 전 체크리스트

발표 전날 한 번 훑어보거나, Claude에게 "이 체크리스트로 전체 점검해줘"라고 하면 됩니다.

- [ ] 모든 쪽의 소제목·제목·쪽번호 위치가 같다
- [ ] 목차가 각 쪽 소제목과 쪽번호에 맞는다 (표지를 넣거나 빼면 다시 확인)
- [ ] 소제목이 없는 쪽이 없다 (이번엔 시연 쪽에 없었음)
- [ ] 찌그러진 상자, 오른쪽 1834를 넘는 요소가 없다
- [ ] 캡처 사진 위쪽이 잘리지 않았고, "[사진] …" 자리표시가 남아 있지 않다
- [ ] 하단 문구·슬로건·장식용 점이 남아 있지 않다
- [ ] 다른 글꼴로 들어간 글상자가 없다
- [ ] 숫자(커밋 수, PR 수, 인원, 날짜)가 최신이고 쪽끼리 같다
- [ ] 노트에 남은 "… 넣기" 메모를 모두 처리했다
- [ ] 발표자별 대본 시간 합이 발표 시간 안에 들어간다

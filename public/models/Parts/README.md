# 캐릭터 꾸미기 부품 (#56)

캐릭터는 3D 모델 하나(`../character-a.glb`)에 스킨 그림(1024×1024) 한 장을 입힙니다. 스킨은 화면이 겹겹이 만듭니다(`src/avatar/composeSkin.ts`).

```
맨몸(고른 피부색) → 눈 → 입 → 눈썹 → 머리카락 → 하의 → 신발 → 상의
```

부품은 스킨과 같은 1024×1024 크기에 **자기 자리만 그리고 나머지는 투명**인 PNG 입니다. 한 부품은 파일 1~3장입니다.

| 파일 | 뜻 |
|---|---|
| `이름-tint.png` | 고른 색을 입힐 부분. **흰색·회색으로** 그립니다. 흰색은 고른 색 그대로, 회색은 그만큼 어둡게 입혀집니다 |
| `이름.png` | 색이 고정인 부분 (눈 흰자·동공, 단추, 신발 밑창 등). 색-입히기 그림 위에 얹힙니다 |
| `이름-closed.png` | 눈 감은 그림 (눈 부품만). 눈을 깜빡일 때 눈 그림 대신 씁니다 |

| 폴더 | 부위 | 입히는 색 |
|---|---|---|
| `eyes/` | 눈 | 눈 색 |
| `brows/` | 눈썹 | 머리 색 |
| `mouth/` | 입 | (고정) |
| `hair/` | 머리카락 | 머리 색 |
| `top/` | 상의 (몸통·팔) | 상의 색 |
| `bottom/` | 하의 (다리) | 하의 색 |
| `shoes/` | 신발 (다리 아래쪽·발바닥) | 신발 색 |

지금 들어 있는 부품은 `scripts/make-avatar-parts.mjs` 가 코드로 그린 간단한 기본 부품입니다. 팀이 그린 부품으로 바꾸거나 더하면 됩니다.

## 새 부품 그리기

1. 안내 그림을 이미지 편집기에서 열고, 그 위에 새 레이어를 만들어 그립니다. 색칠된 자리 밖은 캐릭터에 보이지 않습니다.
   - `templates/head.png`: 눈·눈썹·입·머리카락. 얼굴(빨강)은 8×8 칸으로 나눠 두었고, 흰 네모 두 개가 눈 자리, 검은 네모가 입 자리입니다.
     입 자리는 입 트래킹(#61)의 입 모양이 열리는 곳이라 입은 여기에 그려야 자연스럽습니다.
   - `templates/top.png`: 상의 (몸통 + 두 팔. 팔 옆면의 아래쪽 끝은 손이라 비워 두는 게 자연스럽습니다)
   - `templates/bottom.png`: 하의 (두 다리)
   - `templates/shoes.png`: 신발 (다리 아래쪽 절반과 발바닥)
2. 안내 그림의 색은 그 면이 캐릭터의 어느 쪽인지입니다. 옆면은 그림의 위쪽이 몸의 위쪽입니다.

   | 색 | 면 |
   |---|---|
   | 빨강 | 앞 (얼굴·배) |
   | 파랑 | 뒤 |
   | 초록 | 캐릭터의 왼쪽 |
   | 노랑 | 캐릭터의 오른쪽 |
   | 보라 | 위 |
   | 회색 | 아래 |

3. 색을 고를 수 있게 할 부분은 흰색·회색으로 그려 `이름-tint.png` 로, 색이 고정인 부분은 따로 `이름.png` 로 저장합니다.
   안내 그림 레이어는 끄고 **1024×1024 투명 배경 PNG** 로, 자리 밖은 투명으로 둡니다. 눈이면 감은 눈도 `이름-closed.png` 로 그립니다.
4. `src/avatar/parts.json` 의 그 부위 목록에 한 줄 추가합니다. id 는 영문 소문자·숫자·`-` 로 32자까지입니다.
   ```json
   { "id": "hoodie", "name": "후드티", "tint": "/models/Parts/top/hoodie-tint.png", "file": "/models/Parts/top/hoodie.png" }
   ```

`node scripts/make-avatar-parts.mjs` 를 다시 돌리면 기본 부품과 안내 그림만 새로 만들고, `parts.json` 에 직접 추가한 줄은 그대로 둡니다.

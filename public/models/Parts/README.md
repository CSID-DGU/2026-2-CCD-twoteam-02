# 캐릭터 꾸미기 부품 (#56, #293)

캐릭터는 3D 모델 하나(`../character-a.glb`)에 스킨 그림(1024×1024) 한 장을 입힙니다. 스킨은 화면이 겹겹이 만듭니다(`src/avatar/composeSkin.ts`).

```
맨몸(고른 피부색) → 하의 → 신발 → 상의 (예전처럼 칠한 머리카락 그림이 있으면 그것도)
```

**눈썹·눈·입은 스킨에 그리지 않고**, 얼굴 앞에 붙인 판에 스티커처럼 얹습니다(`src/tracking/useFace.ts`). 사용자가 꾸미기 창에서 눈 간격·높이·크기, 입 높이·크기를 옮길 수 있어서입니다(#293). 눈 깜빡임과 회의실에서 말할 때의 벌린 입도 이 판의 그림만 바꿉니다.

- **머리카락은 머리에 붙이는 입체(3D) 부품**입니다(#296). 아래 "입체 머리카락" 참고.
- 스킨 부품(옷·신발)은 스킨과 같은 1024×1024 크기에 **자기 자리만 그리고 나머지는 투명**인 PNG 입니다.
- 얼굴 부품(눈·눈썹·입)은 **스티커 그림**입니다. 얼굴 한 변을 1024px(얼굴 8×8칸 중 1칸 = 128px)로 놓은 크기로 그리고, **그림 가운데가 그 부품의 기본 자리**입니다. 눈은 오른쪽(화면 오른쪽) 눈 하나만 그리면 왼쪽은 화면이 좌우를 뒤집어 그립니다. 눈썹은 눈 위에 붙어 같이 움직입니다.
  - 그림 크기: 눈 320×320, 눈썹 256×128, 입 512×256 (가운데만 맞으면 크기는 달라도 됨)
  - `src/avatar/parts.json` 의 `box` 는 그림이 실제로 칠해진 범위(가운데 기준 [왼, 위, 오른, 아래])입니다. 화면이 눈과 입이 겹치지 않게 막을 때 씁니다. 스크립트가 적어 줍니다.

한 부품은 파일 1~2장입니다.

| 파일 | 뜻 |
|---|---|
| `이름-tint.png` | 고른 색을 입힐 부분. **흰색·회색으로** 그립니다. 흰색은 고른 색 그대로, 회색은 그만큼 어둡게 입혀집니다 |
| `이름.png` | 색이 고정인 부분 (눈 흰자·동공, 단추, 신발 밑창 등). 색-입히기 그림 위에 얹힙니다 |

| 폴더 | 부위 | 입히는 색 |
|---|---|---|
| `eyes/` | 뜬 눈 | 눈 색 (하늘색으로 그린 곳이 있는 눈만) |
| `closedEyes/` | 감은 눈 (눈을 깜빡일 때 뜬 눈 대신 보임) | (고정) |
| `brows/` | 눈썹 | 머리 색 |
| `mouth/` | 다문 입 (평소 얼굴에 그려짐) | (고정) |
| `mouthOpen/` | 벌린 입 (회의실에서 말할 때 다문 입 대신 보임) | (고정) |
| `hair/` | 머리카락 (입체 모델 `이름.gltf`) | 머리 색 |
| `top/` | 상의 (몸통·팔) | 상의 색 |
| `bottom/` | 하의 (다리) | 하의 색 |
| `shoes/` | 신발 (다리 아래쪽·발바닥) | 신발 색 |

머리카락(상자를 쌓은 모델)·옷·신발·눈썹은 `scripts/make-avatar-parts.mjs` 가 코드로 만든 간단한 기본 부품입니다. 팀이 그린 부품으로 바꾸거나 더하면 됩니다.
눈(`eyes/`, `closedEyes/`)과 입(`mouth/`, `mouthOpen/`)은 김현이 2048×2048 얼굴 캔버스(`art/face-guide/그리기-틀-2048.png` 를 밑그림으로, 그리는 법은 `art/README.md`)에 크게 그려 `scripts/import-face-drawings.mjs` 로 넣습니다. 바깥 흰 바탕을 지우고, 선만 그린 칸은 정한 색으로 채우고, 파랑·하늘색은 눈 색을 입힐 그림으로 나눠 스티커로 만듭니다. 눈은 한쪽만 그리면 되고 왼쪽 눈 자리에 그렸으면 뒤집어 씁니다. 원본 그림은 `art/face-drawings/` 에 있습니다.

## 새 부품 그리기

1. 안내 그림을 이미지 편집기에서 열고, 그 위에 새 레이어를 만들어 그립니다. 색칠된 자리 밖은 캐릭터에 보이지 않습니다.
   - `templates/head.png`: 머리 둘레. 얼굴(빨강)은 8×8 칸으로 나눠 두었고, 흰 네모 두 개가 눈 기본 자리, 검은 네모가 입 기본 자리입니다.
     눈·눈썹·입은 여기에 그리지 않고 위의 스티커 그림으로 그립니다(앞머리가 이 자리를 가리지 않게만 주의).
   - `templates/top.png`: 상의 (몸통 + 두 팔. 팔 옆면의 아래쪽 끝은 손이라 비워 두는 게 자연스럽습니다)
   - `templates/bottom.png`: 하의 (두 다리)
   - `templates/shoes.png`: 신발 (다리 아래쪽 절반과 발바닥)
2. 안내 그림의 색은 그 면이 캐릭터의 어느 쪽인지입니다. 옆면은 그림의 위쪽이 몸의 위쪽입니다.

   | 색 | 면 |
   |---|---|
   | 빨강 | 앞 (얼굴·배) |
   | 파랑 | 뒤 |
   | 초록 | 캐릭터의 왼쪽 |
   | 노랑 | 캐릭터의 오른쪽 |
   | 보라 | 위 |
   | 회색 | 아래 |

3. 색을 고를 수 있게 할 부분은 흰색·회색으로 그려 `이름-tint.png` 로, 색이 고정인 부분은 따로 `이름.png` 로 저장합니다.
   안내 그림 레이어는 끄고 **1024×1024 투명 배경 PNG** 로, 자리 밖은 투명으로 둡니다. (눈·눈썹·입은 위의 스티커 그림 크기로)
4. `src/avatar/parts.json` 의 그 부위 목록에 한 줄 추가합니다. id 는 영문 소문자·숫자·`-` 로 32자까지입니다.
   ```json
   { "id": "hoodie", "name": "후드티", "tint": "/models/Parts/top/hoodie-tint.png", "file": "/models/Parts/top/hoodie.png" }
   ```

`node scripts/make-avatar-parts.mjs` 를 다시 돌리면 기본 부품과 안내 그림만 새로 만들고, `parts.json` 에 직접 추가한 줄은 그대로 둡니다.

## 입체 머리카락 (#296)

머리카락은 머리(head) 뼈에 붙이는 3D 모델(`.gltf`·`.glb`)입니다. 고개를 돌리면 같이 돌고, 고른 머리 색이 입혀집니다.
캐릭터 몸처럼 빛 대신 면 방향마다 밝기를 다르게 칠합니다(위 밝게, 옆·뒤 어둡게). `src/avatar/partModel.ts`, `src/tracking/useHair.ts`

- **좌표:** 머리 뼈 안쪽 좌표로 만듭니다. 머리는 가로 -4~4, 세로 0(턱)~8(정수리), 깊이 -4~4인 상자이고 **얼굴이 +z 쪽**입니다.
- **색:**
  - 고른 머리 색은 모델 색에 곱해집니다. 그래서 머리카락은 **흰색·회색**으로 칠합니다(진할수록 어둡게).
  - 재질(그림) 이름에 `fixed` 가 들어간 부분은 색을 입히지 않고 칠한 색 그대로 둡니다(예: 머리핀).
- **목록:** `src/avatar/parts.json` 의 `hair` 에 `{ "id": "이름", "name": "보이는 이름", "model": "/models/Parts/hair/이름.glb" }` 를 추가합니다.
  - 크기: Blockbench 는 1칸을 1/16 로 내보내서 앱이 16배 키워 붙입니다. 코드로 만든 머리도 같은 단위입니다. 다른 프로그램으로 단위가 다르게 만든 모델만 `"modelScale"` 을 적습니다.

### Blockbench 로 만들기

[Blockbench](https://www.blockbench.net)(무료)로 네모 상자를 쌓아 만듭니다. 그림이 들어간 사용법은 **`art/hair/사용법.md`** 입니다.
시작 파일 `art/hair/머리-시작.bbmodel` 에는 머리 크기 확인용 상자, 얼굴 쪽 표시, 기본 머리 5개(예시), 그리고 빈 `내 머리` 묶음이 있습니다.
`내 머리` 묶음 안의 상자만 내보내지고, 나머지 묶음은 내보내지 않게 해 두었습니다.
고치는 원본(`id.bbmodel`)은 `art/hair/` 에, 내보낸 `id.gltf` 는 바로 이 폴더(`public/models/Parts/hair/`)에 저장하고 위의 목록에 한 줄 추가합니다(`modelScale` 은 적지 않음). 같은 파일을 두 곳에 두지 않습니다.

- `bob.gltf`(일반 단발): 김현이 메쉬로 만든 첫 머리. 원본 `.bbmodel` 은 텍스처 단발을 만들며 덮어써져 남아 있지 않습니다.
- `bob-textured.gltf`(텍스처 단발): 상자에 결을 칠한 머리. 원본은 `art/hair/bob-textured.bbmodel`.

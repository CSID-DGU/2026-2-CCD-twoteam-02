# 캐릭터 원본 그림·모델 (#293, #296)

캐릭터의 눈·입은 얼굴 앞 판에 스티커처럼 얹고, 사용자가 위치와 크기를 옮길 수 있다(`public/models/Parts/README.md`).
그래서 스킨(1024×1024)에 작게 그리지 않고, **얼굴 하나를 2048×2048 캔버스로 놓고 크게** 그린다. 이 폴더가 그 원본이다.

| 폴더 | 내용 |
|---|---|
| `face-guide/그리기-틀-2048.png` | 프로크리에이트 밑그림. 그리는 틀·가운데 십자·얼굴 칸만 있다 |
| `face-guide/얼굴-지도-2048.png` | 설명 그림. 그리는 틀, 사용자가 옮길 수 있는 범위와 거리(px) |
| `face-drawings/` | 김현이 그린 원본(새 눈 1~17, 새 입 1~14). 앱에 들어간 부품은 여기서 만든다 |
| `hair/머리-시작.bbmodel` | 입체 머리카락을 Blockbench 로 만들 때 여는 시작 파일 |
| `hair/사용법.md` | Blockbench 로 머리카락 만드는 법 (그림 포함) |
| `hair/id.bbmodel` | 김현이 만든 머리카락 원본(예: `bob-textured` 텍스처 단발). 내보낸 `.gltf` 는 `public/models/Parts/hair/` 에만 둔다 |

## 숫자 (얼굴 2048×2048, 1칸 = 256px)

| 부품 | 그리는 틀 | 가운데 | 사용자가 옮길 수 있는 거리 |
|---|---|---|---|
| 눈 (한쪽) | 448 × 448 | 왼쪽 (576, 1120), 오른쪽 (1472, 1120) | 위 320 · 아래 192 · 좌우 192 (두 눈은 좌우 반대로 움직여 간격이 바뀜) |
| 입 (다문·벌린 같은 틀) | 1024 × 480 | (1024, 1664) | 위 192 · 아래 128 (아래 끝 = 턱) |

- 크기는 가운데를 기준으로 80~120%, 눈만 150%까지. 눈은 앱에서 그린 크기의 1.3배로 놓는다(`avatarLogic.EYE_SCALE`).
- 눈썹은 높이·크기를 따로 조절하고 간격만 눈을 따라간다.
- 눈과 눈썹·입이 겹치거나 얼굴 밖으로 나가는 곳에서는 화면의 막대가 멈춘다.
- 선 굵기 견본(밑그림 왼쪽 아래 검은 선) = 35px. 모든 그림에 같은 굵기를 쓰면 굵기가 맞는다.

## 그리는 법

1. `그리기-틀-2048.png` 를 2048×2048 캔버스에 깔고, 부품마다 **레이어를 따로** 만들어 검정 틀 안에 그린다.
   - 눈은 **한쪽만** 그린다. 왼쪽·오른쪽 어느 눈 자리에 그려도 되고, 반대쪽은 화면이 좌우를 뒤집어 그린다.
   - 뜬 눈과 감은 눈은 따로 고르는 칸이라, 뜬 눈마다 감은 눈을 그릴 필요는 없다.
   - 다문 입과 벌린 입은 같은 입 틀에 따로 그린다.
2. 색 (칠해서 내보내면 그대로 쓰고, 선만 그리면 칸마다 색을 정해 채운다)

   | 부분 | 색 |
   |---|---|
   | 선 | 검정 |
   | 흰자, 반짝임, 치아 | 흰색 |
   | **사용자가 고른 눈 색으로 바뀌는 곳** | 파랑·하늘색. 진할수록 고른 색도 진하게 입혀진다. 이 색이 없는 눈은 눈 색을 고를 수 없다 |
   | 혀 | 붉은색 |
   | 벌린 입 안 | 까만색 |
3. 내보낼 때 **밑그림 레이어와 배경을 끄고**, 레이어 하나씩 **2048×2048 그대로** 투명 PNG 로 내보내 `face-drawings/` 에 넣는다.

## 앱에 넣는 법

`scripts/import-face-drawings.mjs` 위쪽의 `DRAWINGS` 표에 [파일, 칸, id, 이름, 칸 채우기 색] 을 적고 돌린다.
칸은 `eyes`(뜬 눈)·`closedEyes`(감은 눈)·`mouth`(다문 입)·`mouthOpen`(벌린 입).

```
node scripts/import-face-drawings.mjs
```

스티커 그림(`public/models/Parts/칸/id.png`)과 `src/avatar/parts.json` 줄이 생긴다. 시험만 해 볼 때는 `node scripts/import-face-drawings.mjs art/face-drawings 내보낼폴더` 로 그 폴더에만 쓴다.
선만 그린 칸의 색(`fill`)은 칸의 가운데가 위에 있는 것부터(같으면 왼쪽부터) 1, 2, 3 … 순서로 적는다.

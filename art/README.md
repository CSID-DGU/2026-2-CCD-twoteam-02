# 캐릭터 원본 그림·모델 (#293, #296)

캐릭터의 눈·입은 얼굴 앞 판에 스티커처럼 얹고, 사용자가 위치와 크기를 옮길 수 있다(`public/models/Parts/README.md`).
그래서 스킨(1024×1024)에 작게 그리지 않고, **얼굴 하나를 2048×2048 캔버스로 놓고 크게** 그린다. 이 폴더가 그 원본이다.

| 폴더 | 내용 |
|---|---|
| `face-guide/그리기-틀-2048.png` | 프로크리에이트 밑그림. 그리는 틀·가운데 십자·얼굴 칸만 있다 |
| `face-guide/얼굴-지도-2048.png` | 설명 그림. 그리는 틀, 사용자가 옮길 수 있는 범위와 거리(px) |
| `face-drawings/칸/id.png` | 김현이 그린 원본. 칸(`eyes`·`closedEyes`·`brows`·`mouth`·`mouthOpen`)마다 폴더를 나누고 파일 이름은 부품 id 와 같다. 앱에 들어간 부품은 여기서 만든다 |
| `clothes-guide/` | 상의·하의·신발 격자판 밑그림 (`상의-`, `하의-`, `신발-그리기-틀-2048.png`. 면 이름과 색 규칙이 적혀 있다) |
| `clothes-drawings/칸/id.png` | 그린 옷 원본 (칸은 `top`·`bottom`·`shoes`). 파일 이름은 부품 id 와 같다 |
| `hair/머리-시작.bbmodel` | 입체 머리카락을 Blockbench 로 만들 때 여는 시작 파일 |
| `hair/사용법.md` | Blockbench 로 머리카락 만드는 법 (그림 포함) |
| `hair/id.bbmodel` | 김현이 만든 머리카락 원본(예: `bob-textured` 텍스처 단발). 내보낸 `.gltf` 는 `public/models/Parts/hair/` 에만 둔다 |

## 숫자 (얼굴 2048×2048, 1칸 = 256px)

| 부품 | 그리는 틀 | 가운데 | 사용자가 옮길 수 있는 거리 |
|---|---|---|---|
| 눈 (한쪽) | 448 × 448 | 왼쪽 (576, 1120), 오른쪽 (1472, 1120) | 위 320 · 아래 192 · 좌우 192 (두 눈은 좌우 반대로 움직여 간격이 바뀜) |
| 입 (다문·벌린 같은 틀) | 1024 × 480 | (1024, 1664) | 위 192 · 아래 128 (아래 끝 = 턱) |

- 크기는 가운데를 기준으로 80~120%, 눈만 150%까지. 눈은 앱에서 그린 크기의 1.3배로 놓는다(`avatarLogic.EYE_SCALE`).
- 눈썹은 높이·크기를 따로 조절하고 간격만 눈을 따라간다.
- 눈과 눈썹·입이 겹치거나 얼굴 밖으로 나가는 곳에서는 화면의 막대가 멈춘다.
- 선 굵기 견본(밑그림 왼쪽 아래 검은 선) = 35px. 모든 그림에 같은 굵기를 쓰면 굵기가 맞는다.

## 그리는 법

1. `그리기-틀-2048.png` 를 2048×2048 캔버스에 깔고, 부품마다 **레이어를 따로** 만들어 검정 틀 안에 그린다.
   - 눈은 **한쪽만** 그린다. 왼쪽·오른쪽 어느 눈 자리에 그려도 되고, 반대쪽은 화면이 좌우를 뒤집어 그린다.
   - 뜬 눈과 감은 눈은 따로 고르는 칸이라, 뜬 눈마다 감은 눈을 그릴 필요는 없다.
   - 다문 입과 벌린 입은 같은 입 틀에 따로 그린다.
2. 색 (칠해서 내보내면 그대로 쓰고, 선만 그리면 칸마다 색을 정해 채운다)

   | 부분 | 색 |
   |---|---|
   | 선 | 검정 |
   | 흰자, 반짝임, 치아 | 흰색 |
   | **사용자가 고른 눈 색으로 바뀌는 곳** | 파랑·하늘색. 진할수록 고른 색도 진하게 입혀진다. 이 색이 없는 눈은 눈 색을 고를 수 없다 |
   | 혀 | 붉은색 |
   | 벌린 입 안 | 까만색 |
3. 내보낼 때 **밑그림 레이어와 배경을 끄고**, 레이어 하나씩 **2048×2048 그대로** 투명 PNG 로 내보내 `face-drawings/칸/` 에 `id.png` 로 넣는다(예: `face-drawings/eyes/sparkle.png`).

## 앱에 넣는 법

`scripts/import-face-drawings.mjs` 위쪽의 `DRAWINGS` 표에 [칸, id, 이름, 칸 채우기 색] 을 적고 돌린다. 그림은 `face-drawings/칸/id.png` 에서 찾는다.
예전 그리기 틀(눈 448, 가운데 높이 1120)에 그린 눈은 `oldFrame: true` 를 붙인다. 예전 자리로 자르고, 예전 모습과 같게 1.3배(`scale`)로 놓는다.
지우지 않고 꾸미기 창에서만 내리려면 `src/avatar/parts.json` 의 그 부품에 `"hidden": true` 를 적는다. 이미 고른 사람의 캐릭터에는 그대로 보이고, 스크립트를 다시 돌려도 이 표시는 남는다.
칸은 `eyes`(뜬 눈)·`closedEyes`(감은 눈)·`brows`(눈썹)·`mouth`(다문 입)·`mouthOpen`(벌린 입).
눈썹은 검정으로 한쪽만 그린다. 앱에서는 진하게 칠한 만큼 고른 머리 색이 입혀진다.

```
node scripts/import-face-drawings.mjs
```

스티커 그림(`public/models/Parts/칸/id.png`)과 `src/avatar/parts.json` 줄이 생긴다. 시험만 해 볼 때는 `node scripts/import-face-drawings.mjs art/face-drawings 내보낼폴더` 로 그 폴더에만 쓴다.
선만 그린 칸의 색(`fill`)은 칸의 가운데가 위에 있는 것부터(같으면 왼쪽부터) 1, 2, 3 … 순서로 적는다.

## 상의 그리는 법 (#56)

틀은 몸의 면을 칸으로 펼쳐 놓은 격자판이다. 한 칸은 머리카락 그림 한 칸과 같은 크기이고, 캔버스 전체는 32×32칸이다. 몸통 앞은 8×9칸, 옆은 6×9칸, 팔은 4×11칸이다.

김현은 피그마 파일 [상의 그리기 틀](https://www.figma.com/design/ssTikA0i3RlOmsGZOdX4HH)에서 그린다. 면마다 사각형이 있어 위치를 맞추기 쉽다. 다른 프로그램에서는 `clothes-guide/상의-그리기-틀-2048.png` 를 밑그림으로 쓴다.

### 피그마에서 만드는 순서

1. `옷 1` 프레임을 복제한다(`⌘D`). 옷 한 벌에 프레임 하나를 쓴다.
2. `여기에 그리기` 프레임 안의 흰 사각형이 옷의 각 면이다(`몸통 앞`, `팔 바깥` 등). 색을 바꾸거나 크기를 줄이고, 그 위에 도형을 얹어 그린다. 사각형 가장자리에 붙이면 위치가 맞는다.
3. 구멍을 낼 때(목선 등): 구멍 모양을 도형 위에 겹쳐 그리고, 둘을 같이 선택해 불리언 메뉴의 **Subtract selection**(빼기)을 누른다. 색이 바뀌면 다시 칠한다.
4. **뒤에 다른 도형이 깔려 있으면 구멍과 빈 곳이 뚫리지 않는다.** 흰 `몸통 앞` 위에 새 도형을 그렸다면 `몸통 앞` 을 지운다. 레이어 목록에서 아래에 있을수록 뒤에 깔린 도형이다.
5. **`여기에 그리기` 프레임만 선택해** 오른쪽 아래 Export 로 PNG(1x)를 내보낸다. 바깥의 `옷 1` 을 내보내면 회색 배경·이름표·빨간 선이 같이 나와 쓸 수 없다. 제대로 내보내면 그림 밖이 투명하다.
6. PNG 를 덮어써도 앱은 바로 바뀌지 않는다. 가져오기 스크립트를 돌리고(아래) 페이지를 새로고침한다.

### 하의·신발

칸 크기는 상의와 같다(1칸 = 64px). 왼쪽만 그리면 오른쪽은 좌우를 뒤집어 만든다. 그리는 칸은 다리 안쪽·앞·바깥·뒤가 한 줄로 이어진다. `안쪽` 면은 두 다리가 맞닿아 서 있으면 보이지 않는다.

피그마에서 흰 사각형을 만들 때의 숫자(`여기에 그리기` 프레임 기준):

| 칸 | 이름 | X | Y | W | H |
|---|---|---|---|---|---|
| 하의 | 다리 위 | 384 | 0 | 256 | 256 |
| 하의 | 다리 안쪽 / 앞 / 바깥 / 뒤 | 128 / 384 / 640 / 896 | 256 | 256 | 640 |
| 신발 (운동화 높이) | 신발 안쪽 / 앞 / 바깥 / 뒤 | 128 / 384 / 640 / 896 | 768 | 256 | 128 |
| 신발 | 발바닥 | 384 | 896 | 256 | 256 |

- 반바지는 Y 576 까지 칠하면 틀의 "반바지 끝"이다.
- 신발 높이를 바꾸면 아래 끝(896)은 그대로 두고 Y 와 H 를 바꾼다. 부츠는 Y 608, H 288 이다.
- 발바닥 칸은 위쪽 끝이 앞코, 오른쪽이 바깥쪽이다.
- 신발은 하의 위에 입혀진다. 허리 위(몸통)는 하의로 칠할 수 없다.

1. 칸 안을 칠한다. 옷마다 프레임이나 레이어를 따로 만든다.
   - 몸통은 오른쪽·앞·왼쪽·뒤가 한 줄로 이어져 있어, 칸 경계를 넘어 그대로 그리면 옷에서도 이어진다.
   - 팔은 왼팔만 그린다. 오른팔은 좌우를 뒤집어 만든다(바깥쪽 무늬는 양팔 모두 바깥에 온다).
   - 비워 둔 곳은 맨살이 보인다. 배꼽티는 배를, 반팔은 "반팔 끝" 아래를 비운다.
   - 틀에 없는 아랫면은 앞면의 아래 끝 줄로 채운다.
2. 색

   | 칠한 색 | 앱에서 |
   |---|---|
   | 흰색 | 고른 상의 색 |
   | 그 밖의 색 | 칠한 색 그대로 (가디건, 단추, 선, 무늬 등. 회색·검정도 그대로) |
   | 반투명 | 그만큼 맨살이 비친다 |

   면마다 밝기는 스크립트가 넣으므로 칠하지 않는다.
3. 스킨에서 몸통 앞면은 117×132px 이다. 선은 16px 이상으로 굵게, 무늬는 크게 그린다. 더 가는 선은 흐리게 보인다.
4. 밑그림을 끄고 2048×2048 투명 PNG 로 내보내 `clothes-drawings/top/id.png` 로 넣는다.
5. `scripts/import-clothes-drawings.mjs` 위쪽의 `DRAWINGS` 표에 [칸, id, 이름] 을 적고 돌린다.

```
node scripts/import-clothes-drawings.mjs
```
